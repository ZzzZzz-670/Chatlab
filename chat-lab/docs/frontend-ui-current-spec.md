## 1. 当前产品定位

当前前端是移动端优先的亲子教育 AI 对话原型，核心体验是：

- 家长从孩子最近的一件小事开始描述。
- AI 把对话沉淀为成长信号、孩子理解卡、沟通预演、小档案、观察记录。
- 二级界面用于查看沉淀结果。
- 三级界面用于查看来源、记录详情、孩子端填写、孩子视角摘要。

当前设计不是营销首页，也不是完整多端后台。它是一个 375pt iPhone 设计稿思路下的单列移动应用壳。

### 首屏初始消息

AI 欢迎：

```text
可以从孩子最近的一件小事说起。
开心的、别扭的、说不清的都可以。
我会陪你慢慢把孩子的状态和相处节奏看清楚。
```

用户示例：

```text
昨天他没有被催，自己写了一会儿作业，但写完一段以后又拿手机，我们又差点吵起来。
```

AI 普通回复：

```text
这个变化挺值得记一下。
如果他平时不太主动开始学习，这次愿意先写一段，至少说明当时的启动窗口是打开的。
我想先看一个细节：他拿手机是在完全不想写之前，还是已经完成了一小段之后？
```

记忆提示：

```text
已记录一个近期变化
```

记忆详情：

```text
这次记下的是：孩子在没有被连续催促的情况下出现过主动启动。后面再聊作业、拖延和手机时，我会一起参考。
```

继续话题回复：

```text
我们可以继续看上次那个点：孩子拿手机更像是在逃避，还是在确认完成一段以后能不能真的休息。
```

输入后模拟回复：

```text
我先把这件事记成一个具体场景。这里面最值得看的不是孩子做得够不够好，而是他是在什么条件下更容易启动、什么条件下更容易退回去。
```

## 19. 当前需要统一微调的点

这些不是 bug，但后续统一设计时建议一次性确定：

1. 卡片圆角不完全一致：聊天卡片 `22px`，二级/三级卡片 `12px`，大卡片 `22px`。
2. 按钮形态不完全一致：聊天卡片按钮是 pill，二级/三级按钮是 `12px` 圆角。
3. TopBar 图标目前是文字字符 `‹`、`≡`、`···`，不是图标库。
4. 二级/三级已按豆包卡片规范调整，但聊天内结构化卡片仍保留原型风格。
5. `/character`、`/community`、`/english`、`/exam`、`/qa`、`/schedule` 仍是占位页，需要决定是否纳入同一视觉系统。
6. 孩子端填写页的进度条仍用默认蓝色，只有在小档案/观察记录 scoped 页里有蓝紫渐变覆盖。
7. 文案里多处使用“清北”定位，后续需要确认品牌口径是否保留。

## 20. 建议你微调时优先确认的变量

建议先确认这些全局变量，再细调单页：

- 主品牌色：`#2563EB` 还是 `#1677FF`
- 结构化卡片圆角：统一 `12px`、`16px` 还是保留聊天卡片 `22px`
- 按钮形态：pill 还是 12px 圆角
- 二级/三级标题颜色：`#1D2129` 是否全局替换 `#1F2937`
- 正文字号：聊天保留 `17px`，还是统一为豆包规范 `15px / 24px`
- 辅助文字：`#9AA3B2` 与 `#86909C` 是否统一
- “精准度待完善”提示是否保留黄底，还是改为灰底低干扰
- “清北”相关文案是否继续作为核心卖点
