# 04C_孩子行为候选解释库.md

## 一、文档定位

本文是「对话实验室」日常对话 Agent 的孩子行为候选解释库。

它属于日常 Agent 的底层理解材料，不是前台功能文档。它服务于：

- 孩子视角解释；
- 成长信号识别；
- 记忆沉淀；
- 待观察点生成；
- 沟通预演；
- 纠偏；
- 阶段性小观察。

本文解决的问题是：

> 家长描述孩子某个行为时，Agent 不能只按表面现象判断，也不能直接接受家长定性，而要先生成多个候选解释，再结合孩子画像、家长叙述和家庭互动记录，选出当前最合理、最有帮助的解释方向。

---

## 二、使用原则

## 1. 候选解释不是结论

每个孩子行为背后都可能有多种原因。

例如：

```text
孩子拖作业
```

不能直接解释为：

```text
孩子懒 / 不自觉 / 没责任感
```

应先保留候选：

```text
启动困难
任务边界不清
科目真实卡点
做完后还会被加任务
疲惫后恢复不足
怕暴露短板
对被安排缺少参与感
用拖延保留主动权
```

前台通常只表达最贴近当前画像和事实的一个方向，不把所有候选都讲出来。

---

## 2. 先看行为发生的位置

很多行为的含义取决于它出现在哪个时间点。

例如手机：

| 出现位置 | 可能含义 |
|---|---|
| 学习开始前 | 逃避压力、启动困难、抗拒进入任务 |
| 学习中途 | 卡点、疲惫、挫败、注意力断裂 |
| 完成一段后 | 恢复需求、休息边界、自主权 |
| 无任务时也停不下 | 即时反馈依赖、习惯问题 |
| 睡前 | 情绪缓冲、睡眠节律、白天压力释放 |

所以 Agent 要优先确认：

```text
这个行为发生在开始前、中途、完成后，还是无任务时？
```

---

## 3. 先拆事实，再谈原因

家长常常会把事实和解释混在一起。

家长说：

```text
他就是不想学。
```

Agent 要先还原：

```text
孩子具体做了什么？
是在什么任务上不动？
是所有任务都这样，还是某一类任务这样？
是开始前拖，还是做一半停？
家长怎么介入？
孩子怎么反应？
```

只有事实足够后，才能写入画像。

---

## 4. 不要把孩子行为道德化

日常 Agent 不应把孩子行为轻易解释为：

- 懒；
- 自私；
- 没责任感；
- 不懂事；
- 故意气家长；
- 叛逆；
- 玻璃心；
- 沉迷；
- 没救。

这些词多半是家长在压力下的评价，不是可直接写入的孩子画像。

---

## 5. 孩子行为常常有“保护功能”

很多看似负面的行为，其实是在保护某种东西：

| 表面行为 | 可能保护 |
|---|---|
| 拖延 | 自主权、任务总量、失败退路 |
| 沉默 | 冲突降温、面子、真实想法 |
| 表面答应 | 关系稳定、父母情绪、当下安全 |
| 说无所谓 | 自尊、失败后的退路 |
| 刷难题 | 优秀感、自我形象 |
| 拿手机 | 恢复时间、情绪缓冲、自己说了算的空间 |
| 不问问题 | 面子、不会被暴露、避免被评价 |
| 顶嘴 | 主动权、边界感、不被定义 |

前台表达时不要说得太重，只需自然点出一层：

```text
他这样不一定是完全不想做，也可能是在保留一点自己说了算的空间。
```

---

## 6. 当前解释要结合已有画像

候选解释不是凭空选择。

选择优先级：

```text
当前事实
>
近期多次记录
>
孩子问卷
>
高相关孩子画像
>
家庭互动模式
>
首次诊断卡
>
通用知识库
```

如果当前事实和旧画像冲突，优先当前事实，并触发纠偏候选。

# 三、行为类别总览

```text

9. 敷衍 / 随便 / 无所谓

13. 刷难题 / 假努力
14. 考前回避 / 考后躲避

19. 过度乖巧 / 不表达真实想法
20. 自我否定 / 说自己不行
```

# 四、作业拖延 / 磨蹭

## 1. 常见家长输入

```text
他一写作业就磨蹭。
不盯他根本不动。
坐半天也不开始。
每次都拖到很晚。
他就是不自觉。
他说马上写，结果半小时过去还没动。
```

## 2. 需要先拆出的事实

- 拖延发生在开始前，还是写到一半后；
- 是所有作业都拖，还是某一科明显；
- 家长有没有临时加任务；
- 孩子是否知道做到哪里算结束；
- 拖延前孩子刚从学校回来，还是已经休息过；
- 孩子是否说过“做完还有别的”。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 启动困难 | 坐下前拖很久，一旦开始未必很差 |
| 任务拆解困难 | 不知道先做什么，面对一堆任务发愣 |
| 科目真实卡点 | 某科明显拖，尤其数学、英语、背诵、订正 |
| 任务边界不清 | 做完一项后总有下一项 |
| 疲惫恢复不足 | 放学后明显累、发呆、反应慢 |
| 自主权争夺 | 家长安排越细，孩子越慢 |
| 失败回避 | 怕一开始就发现不会 |
| 外部推动依赖 | 家长不催就不启动，长期形成依赖 |
| 抵抗被评价 | 一写作业就进入被检查、被评价状态 |

## 4. 高价值追问

```text
他是坐下前一直拖，还是写了一段之后才慢下来？
```

或：

```text
他是所有作业都拖，还是某一类特别明显？比如计算、作文、背诵、订正，哪一个最容易拖？
```

## 5. 前台可用表达

```text
我先不把它直接定成不自觉。这里更需要区分：他是开始前那一下特别难推进，还是写到一半遇到卡点才停下来。
```

```text
如果他是一坐下前就拖，很可能不是完全不会，而是进入任务前那一步阻力很大。
```

```text
如果孩子形成了“做完一件还有下一件”的预期，他就容易用磨蹭控制任务总量。
```

## 6. 可写入记忆

### growth_records

```text
孩子近期作业启动前拖延明显。
```

### pending_observations

```text
确认孩子拖延主要发生在开始前，还是写到一半后。
```

### profile_entries

```text
孩子在作业开始前阻力较大，进入状态后未必差。
```

# 五、写到一半停住

## 1. 常见家长输入

```text
他开始倒是开始了，但写一会儿就停。
写着写着就去喝水、上厕所、摸手机。
做一半就说累。
一遇到难题就不动。
```

## 2. 需要先拆出的事实

- 停住时是在什么题型；
- 是难题、计算、作文、背诵、订正还是检查；
- 停住后孩子做什么；
- 家长是否立刻介入；
- 停住后能不能重新回来；
- 这个行为出现频率。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 真实卡点 | 特定题型或科目停住 |
| 挫败感上来 | 一遇到不会就烦 |
| 注意力断裂 | 停住后找小动作 |
| 体力/脑力不足 | 晚上后半段明显下降 |
| 逃避检查 | 快做到要被看见结果时停 |
| 怕暴露短板 | 不愿继续写出错误 |
| 没有分段目标 | 任务太长，不知道阶段结束点 |
| 完成一段后需要恢复 | 停住不是逃避，是需要短恢复 |

## 4. 高价值追问

```text
他停住时，通常是遇到不会的地方，还是已经写完一小段之后想缓一下？
```

## 5. 前台可用表达

```text
写到一半停住，比一开始不写更像是过程中出现了某个阻力。这里要分清：是题目真的卡住，还是完成一段后需要缓一下。
```

## 6. 可写入记忆

```text
孩子在学习过程中容易出现中途停顿，具体原因需区分卡点和恢复需求。
```

# 六、不会也不问 / 说都懂

## 1. 常见家长输入

```text
不会也不问。
你问他哪里不会，他就说都懂。
结果一做又错。
讲了他也点头，但根本没听进去。
他就是什么都不说。
```

## 2. 需要先拆出的事实

- 孩子是不会问，还是不敢问；
- 是不知道哪里不会，还是知道但不说；
- 家长问的时候语气和场景；
- 过去问了以后是否被批评、被讲很久；
- 孩子是否更愿意问同学或老师；
- 是所有科目都这样，还是某科明显。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 不知道怎么问 | 问题模糊，只说“都不会/都懂” |
| 怕暴露不会 | 一问就紧张、回避 |
| 自尊保护 | 基础漏洞不愿承认 |
| 觉得问了也会被说 | 曾经一问就被批评或长篇讲道理 |
| 用“懂了”结束追问 | 点头快，但后续不执行 |
| 对讲解方式有压力 | 家长越讲越多，孩子越关 |
| 不会定位错因 | 做错但说不出错在哪里 |
| 习惯被动等待答案 | 长期缺少主动提问训练 |

## 4. 高价值追问

```text
他是完全说不出哪里不会，还是其实知道哪块不会但不愿意展开说？
```

或：

```text
他问同学、老师会不会比问家长更自然一点？
```

## 5. 前台可用表达

```text
他说“都懂”，不一定是真的都会了，也可能是不想在当下继续暴露自己哪里不会。
```

```text
有些孩子不是不想问，而是不知道怎么把“我不会”拆成一个具体问题。
```

```text
如果每次一问就会被讲很久，他可能会先用“懂了”让这轮沟通停下来。
```

## 6. 可写入记忆

```text
孩子在暴露学习漏洞时可能有回避，具体需区分是不知道怎么问，还是不愿承认不会。
```

# 七、错题订正抗拒

## 1. 常见家长输入

```text
一让他订正错题就烦。
错了也不看。
错题本根本坚持不了。
讲错题他就不耐烦。
他只想赶紧写完，不想复盘。
```

## 2. 需要先拆出的事实

- 抗拒的是订正本身，还是被检查；
- 错题类型是粗心、不会、步骤问题还是理解错误；
- 家长是否把错题和态度挂钩；
- 孩子是否知道错在哪里；
- 是否一订正就暴露基础漏洞。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 错题暴露短板 | 订正时发现自己其实没懂 |
| 自尊受损 | 一看到错题就烦 |
| 过程太繁琐 | 抄题、整理、归类负担大 |
| 不知道怎么复盘 | 只会改答案，不会总结错因 |
| 被评价感强 | 订正变成“你怎么又错” |
| 立即反馈低 | 订正不像刷题有成就感 |
| 历史失败感 | 做过错题本但没坚持，形成抵触 |
| 时间边界不清 | 订正一开始就像无底洞 |

## 4. 高价值追问

```text
他最烦的是看见错题本身，还是订正完要给您检查？
```

## 5. 前台可用表达

```text
错题对孩子来说不只是“改一遍”，它也可能是在重新面对自己哪里不会。尤其如果订正后还要被检查，他会更容易先烦起来。
```

## 6. 可写入记忆

```text
孩子对错题订正存在抵触，可能与暴露短板和被检查感有关。
```

# 八、背诵 / 默写 / 检查抵触

## 1. 常见家长输入

```text
一背单词就烦。
背的时候还行，一默写就崩。
检查他就很不耐烦。
让他复述就说烦死了。
```

## 2. 需要先拆出的事实

- 抵触发生在背之前、背的过程，还是检查时；
- 是英语单词、语文古诗、政史地知识点还是公式；
- 孩子是记不住，还是怕被检查；
- 检查后家长怎么反应；
- 是否存在反复失败经历。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 记忆方法无效 | 背了很久仍记不住 |
| 检查压力大 | 一检查就烦、躲、乱说 |
| 暴露短板羞耻 | 默写错很多后明显烦 |
| 即时挫败强 | 背诵反馈太快，错得明显 |
| 家长反应强化压力 | 错了就被说不用心 |
| 任务枯燥低成就 | 背诵缺少成就感 |
| 复习间隔不合理 | 当天会，第二天忘 |
| 失败次数多形成抗拒 | 看到单词就烦 |

## 4. 高价值追问

```text
他最烦的是开始背之前，还是背完要检查的时候？
```

## 5. 前台可用表达

```text
如果他背的时候还能撑住，但一到检查就烦，问题可能不只是记忆本身，而是“被当场暴露不会”的压力。
```

## 6. 可写入记忆

```text
孩子在背诵检查环节更容易烦躁，可能与暴露错误和即时挫败有关。
```

# 九、表面答应但不执行

## 1. 常见家长输入

```text
他说知道了，结果根本不改。
每次都答应得好好的。
说下次改，下一次还是一样。
他就是敷衍我。
```

## 2. 需要先拆出的事实

- 答应后是否有具体执行计划；
- 家长是否继续追问细节；
- 孩子答应时情绪如何；
- 过去承诺后是否被继续盯；
- 答应是主动提出，还是被迫回应；
- 不执行是忘了、不会做，还是不认同。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 先结束冲突 | 答应很快，但没有细节 |
| 没形成执行计划 | 只有“下次改”，没有怎么改 |
| 不想继续争 | 家长追得越紧，答应越快 |
| 让家长安心 | 用承诺安抚家长情绪 |
| 对承诺失去信任 | 说了也未必改变关系 |
| 执行能力不足 | 想改但不知道怎么做 |
| 不认同要求 | 嘴上答应，内心不接受 |
| 过往经验强化 | 答应可以让冲突快速结束 |

## 4. 高价值追问

```text
他每次说“知道了、我错了”之后，是会开始具体说怎么做，还是更像先让这场冲突停下来？
```

## 5. 前台可用表达

```text
他答应了，不一定代表已经形成了执行计划。有时候“知道了”“下次改”更像是先让这场冲突停下来。
```

```text
如果每次答应都能让争执暂停，这句话就容易慢慢变成一种降温方式，而不是行动计划。
```

## 6. 可写入记忆

```text
孩子可能会用“知道了、下次改”来结束冲突，但后续执行步骤并未形成。
```

# 十、沉默 / 不说话

## 1. 常见家长输入

```text
一问他就不说话。
问什么都沉默。
他就把门一关。
你说他，他也不回应。
我越问他越不说。
```

## 2. 需要先拆出的事实

- 沉默前家长说了什么；
- 是问原因、批评、讲道理，还是安排任务；
- 孩子是低头不说、回房间，还是明显烦躁；
- 沉默后冲突是否升级；
- 孩子平时是否愿意在别的场景说；
- 是否只对家长沉默，还是对老师同学也沉默。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 降低冲突 | 越说越僵时沉默 |
| 不知道怎么解释 | 问原因时说不出 |
| 觉得说了也没用 | 过去解释不被接住 |
| 怕越说越被追问 | 家长连续追问后关闭 |
| 情绪太满 | 眼眶红、烦躁、走开 |
| 保护真实想法 | 不愿把真实想法暴露出来 |
| 对沟通失去信任 | 长期一说就被评价 |
| 被动抵抗 | 用不说话表达不满 |

## 4. 高价值追问

```text
他沉默前，您最后一句更像是在问原因，还是提醒他必须做？
```

或：

```text
他是不说但还能待在那儿，还是会直接回房间、关门？
```

## 5. 前台可用表达

```text
他沉默不一定代表完全没想法。对孩子来说，沉默有时是在让冲突先降下来，至少不会越说越僵。
```

```text
咱们这边是想确认原因，但孩子那边可能先感受到的是被连续追问。
```

## 6. 可写入记忆

```text
孩子在被连续追问时容易沉默，可能是在降低冲突。
```

# 十一、顶嘴 / 怼家长

## 1. 常见家长输入

```text
他现在特别会顶嘴。
说一句回十句。
一说学习就怼我。
他态度特别差。
以前还挺乖，现在越来越犟。
```

## 2. 需要先拆出的事实

- 顶嘴发生在哪类话题；
- 是学习、手机、成绩、朋友、生活习惯还是未来规划；
- 家长前一句是什么；
- 孩子顶嘴内容是表达边界，还是单纯攻击；
- 顶嘴后是否还愿意沟通；
- 最近是否进入青春期、换环境或压力阶段。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 争取主动权 | 被安排时反应强 |
| 对评价防御 | 被说态度、责任感时顶 |
| 边界感增强 | 对私人空间、手机、朋友更敏感 |
| 真实不满终于出口 | 过去很乖，最近突然反弹 |
| 不知道怎么表达需求 | 用冲的话表达边界 |
| 家庭信任下降 | 默认家长不会理解 |
| 压力外溢 | 学校压力回家爆发 |
| 试探家长反应 | 看自己能否有不同意见 |

## 4. 高价值追问

```text
他顶嘴时，是在反驳具体安排，还是更像在反驳“你又不信我”这种感受？
```

## 5. 前台可用表达

```text
顶嘴不一定只是态度差。有时候孩子是在用很冲的方式表达：这件事我不想完全被安排。
```

```text
如果他以前一直很乖，最近突然开始顶，可能说明真实不满终于有了出口，但表达方式还很粗糙。
```

## 6. 可写入记忆

```text
孩子在涉及自主安排的话题上容易顶嘴，可能与边界感和主动权有关。
```

# 十二、敷衍 / 随便 / 无所谓

## 1. 常见家长输入

```text
他说随便。
问他什么都说无所谓。
一副不在乎的样子。
说什么都敷衍。
他根本不上心。
```

## 2. 需要先拆出的事实

- “无所谓”出现在哪个话题；
- 是成绩、选科、学校、朋友、手机、未来规划还是家庭安排；
- 说无所谓时语气是烦、冷、躲，还是平静；
- 后续行为是否真的不在乎；
- 有没有明显回避失败或评价。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 保护自尊 | 表面不在乎，结果出来后仍低落 |
| 避免被继续评价 | 一讨论成绩就无所谓 |
| 对改变无力 | 觉得努力也没用 |
| 不想暴露真实愿望 | 怕说了被否定 |
| 降低家长期待 | 先说不在乎，避免被寄予更高期待 |
| 真实兴趣缺失 | 对很多事都没有主动倾向 |
| 情绪关闭 | 长期疲惫后什么都不想谈 |
| 被动抵抗 | 用随便拒绝参与决策 |

## 4. 高价值追问

```text
他说无所谓之后，结果真的怎么样都行，还是结果不好时他其实会低落？
```

## 5. 前台可用表达

```text
他说无所谓，不一定是真不在乎。很多孩子会用无所谓挡一下，因为一旦承认自己在乎，就更容易面对失败和评价。
```

## 6. 可写入记忆

```text
孩子在被问及成绩或选择时常说无所谓，需继续确认是真不在乎，还是在保护自尊。
```

# 十三、手机 / 游戏 / 短视频

## 1. 常见家长输入

```text
他一有空就玩手机。
手机根本停不下来。
写作业前也玩，写完也玩。
不让玩就急。
他就是沉迷手机。
```

## 2. 需要先拆出的事实

- 手机出现时间；
- 使用内容：游戏、短视频、聊天、查资料、听歌；
- 使用时长；
- 是否能停；
- 是否影响睡眠；
- 是否只在学习冲突后出现；
- 是否有其他恢复方式；
- 家长规则是否稳定。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 学习前逃避压力 | 一到学习前就拿 |
| 完成任务后恢复 | 做完一段后拿 |
| 即时反馈依赖 | 无任务时也停不下 |
| 情绪缓冲 | 心情不好、睡前刷 |
| 社交连接 | 主要聊天、看群 |
| 自主权争夺 | 不让就反应很大 |
| 从冲突中抽离 | 吵完后立刻拿手机 |
| 缺少替代恢复方式 | 除手机外没有放松方式 |
| 规则不稳定 | 有时允许、有时突然收紧 |

## 4. 高价值追问

```text
手机最容易在哪个时间冒出来：开始学习前、写到一半、写完以后，还是没学习任务时也停不下来？
```

## 5. 前台可用表达

```text
手机这件事要看出现时间。如果总是在任务还没开始前出现，可能更偏逃避压力；如果多在完成一段后出现，也可能是在争取一段自己说了算的恢复时间。
```

```text
如果孩子除了手机几乎没有别的稳定恢复方式，手机就不只是娱乐，也承担了情绪缓冲的功能。
```

## 6. 可写入记忆

```text
孩子手机使用需继续区分学习前逃避、完成任务后恢复和无任务时即时反馈依赖。
```

# 十四、情绪爆发 / 哭 / 回房间

## 1. 常见家长输入

```text
他说两句就哭。
突然就崩了。
一说他就回房间。
情绪特别大。
我也没说什么，他反应特别激烈。
```

## 2. 需要先拆出的事实

- 爆发前发生了什么；
- 家长说了哪句话；
- 是否近期压力累积；
- 是否只在某类话题爆发；
- 孩子爆发后是哭、喊、走开还是关门；
- 爆发后能否恢复沟通；
- 最近睡眠、学校、同伴是否变化。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 长期积压 | 小事触发大反应 |
| 旧感受被触发 | 某类话题一碰就爆 |
| 身体疲惫 | 晚上、睡眠不足时明显 |
| 被误解感 | 反复说“你根本不懂” |
| 羞耻感 | 涉及成绩、错误、比较时 |
| 自主权被压缩 | 被安排时爆发 |
| 关闭沟通 | 回房间、关门 |
| 情绪表达能力不足 | 只能哭或喊，无法说清楚 |

## 4. 高价值追问

```text
这次爆发前几天，他有没有已经明显不太对劲，比如话少、睡得晚、回家更累？
```

## 5. 前台可用表达

```text
这次爆发可能不只是因为眼前这一句话。它更像是前面几次没有说出来的东西，在这个点上一起冒出来了。
```

```text
如果孩子反应明显超过这件事本身，通常要看前面有没有连续积压，而不是只盯这一次谁说错了。
```

## 6. 可写入记忆

```text
孩子在特定话题下情绪反应强，需继续确认是否有长期积压或被误解感。
```

# 十五、说没事 / 看起来很累

## 1. 常见家长输入

```text
他看起来很累，但问他又说没事。
回家就不说话。
最近整个人没精神。
问学校怎么样，他就说还行。
```

## 2. 需要先拆出的事实

- 最近睡眠是否变化；
- 学校、同伴、老师是否有变化；
- 成绩是否波动；
- 回家后话是否变少；
- 是身体累，还是情绪低；
- 有没有兴趣下降；
- 有没有食欲、作息变化。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 睡眠不足 | 晚睡、早起、白天困 |
| 学校消耗 | 回家明显话少 |
| 同伴关系压力 | 不愿聊学校、回避朋友话题 |
| 学习压力 | 考试、作业、排名后明显 |
| 情绪关闭 | 问什么都说没事 |
| 不想被追问 | 一问就缩回去 |
| 还没整理清楚 | 说不出具体原因 |
| 保护家长 | 不想让父母担心 |

## 4. 高价值追问

```text
他最近是睡眠明显变少，还是白天回家后话变少？
```

## 5. 前台可用表达

```text
他说“没事”不一定代表真的没压力，也可能是他还没整理清楚，不想在被追问时马上解释。
```

```text
累可能不只是身体累，也可能是学校里的事、学习任务、同伴关系、睡眠不足几件事叠在一起。
```

## 6. 可写入记忆

```text
孩子近期疲惫但表达关闭，需继续确认睡眠、学校消耗和同伴变化。
```

# 十六、刷难题 / 假努力

## 1. 常见家长输入

```text
他基础题不做，老刷难题。
看着很努力，但成绩没起色。
他明知道基础差，还是不愿意补基础。
他每天都在学，但效率很低。
```

## 2. 需要先拆出的事实

- 孩子选择的任务类型；
- 是否回避基础题；
- 刷难题后是否有成就感；
- 基础漏洞是否明显；
- 家长是否强调“你基础太差”；
- 孩子是否在优秀形象上有压力。

## 3. 候选解释

| 候选解释 | 典型线索 |
|---|---|
| 维持优秀感 | 喜欢做难题证明自己 |
| 回避基础漏洞 | 不愿补最该补的 |
| 假努力 | 看起来很忙，但避开关键任务 |
| 自尊保护 | 基础错会让他难堪 |
| 成就感依赖 | 难题做出来有快感 |
| 任务选择失衡 | 不知道如何安排优先级 |
| 焦虑性学习 | 用忙碌缓解焦虑 |
| 家长评价压力 | 被说基础差后更回避基础 |

## 4. 高价值追问

```text
他刷难题以后，是更踏实了，还是更像重新证明了自己还挺厉害？
```

## 5. 前台可用表达

```text
如果他明知道基础题更该补，却总去碰难题，这未必只是上进，也可能是在维持“我其实还是很强”的感觉，绕开基础漏洞带来的不舒服。
```

## 6. 可写入记忆

```text
孩子可能通过刷难题维持优秀感，回避基础漏洞带来的挫败。
```

# 二十三、自我否定 / 说自己不行

## 2. 候选解释

|---|---|

| 避免继续努力 | 先说不行，降低期待 |

| 目标过高 | 达不到期待后否定自己 |
| 情绪低谷 | 暂时性自我否定 |

## 3. 高价值追问

```text
他说自己不行，是只在某一科上这样说，还是最近很多事都这么说？
```

## 4. 前台可用表达

```text
他说自己不行，不一定是真的放弃，也可能是在给自己留一点退路：如果我本来就不行，那失败就没那么难堪。
```

---

# 二十四、候选解释选择规则

## 1. 优先选择能解释多个现象的解释

如果一个解释能同时解释：

- 拖延；
- 沉默；
- 表面答应；
- 手机；
- 不问问题；

它优先级更高。

例如：

```text
孩子担心做完后被继续加任务
```

可能同时解释：

- 作业磨蹭；
- 做完后立刻拿手机；
- 周末安排抵触；
- 对效率提升没动力。

---

## 2. 优先选择有当前事实支撑的解释

不要因为某个解释听起来深，就优先使用。

例如：

```text
自尊保护
```

只有在出现以下线索时才优先：

- 不愿补基础；
- 喜欢刷难题；
- 说无所谓但结果不好会低落；
- 怕被检查；
- 不愿承认不会。

---

## 3. 优先选择对家长下一步理解有帮助的解释

有些解释虽然可能正确，但对当前回复帮助不大。

日常 Agent 前台只讲对家长最有用的一层。

例如：

家长只是问“他为什么拿手机”，前台不必讲完整机制，只需说：

```text
这要看手机出现的时间。如果是在完成一段任务后，它可能不只是逃避，也可能是在找恢复时间。
```

---

## 4. 置信度不足时写待观察

如果无法确定，不要强行写画像。

应返回：

```text
pending_observation_candidates
```

前台可说：

```text
这个点还要再确认一下，不急着定成沉迷或不自觉。
```

# 二十五、从候选解释到记忆写入

## 1. 写入 growth_records

适合：

- 单次具体事件；
- 相对旧画像有变化；
- 值得后续对照。

示例：

```text
孩子今天主动提到学校里的事。
```

## 2. 写入 profile_entries

适合：

- 多次出现；
- 有较稳定证据；
- 家长确认；
- 孩子问卷支持；
- 可用于后续判断。

示例：

```text
孩子在被连续追问时容易沉默，可能是在降低冲突。
```

## 3. 写入 pending_observations

适合：

- 信息重要但不确定；
- 存在两种以上候选解释；
- 需要后续验证；
- 与旧画像存在潜在冲突。

示例：

```text
确认孩子拿手机更偏学习前逃避，还是完成任务后的恢复。
```

## 4. 写入 correction_candidates

适合：

- 新信息改变旧判断；
- 家长否定旧判断；
- 多次新记录显示旧判断不再适用；
- 旧诊断卡解释范围过宽。

示例：

```text
旧判断“手机主要是逃避学习”需缩小范围，新增“完成任务后恢复需求”。
```

# 二十六、禁止事项

## 1. 禁止单因归因

不要说：

```text
他就是因为压力大。
他就是缺内驱力。
他就是沉迷手机。
```

## 2. 禁止过度深挖

日常 Agent 不是每轮都要挖出“深层机制”。

如果只是普通变化，轻回应即可。

## 3. 禁止把候选解释当确定结论

不要说：

```text
孩子一定是在保护自尊。
```

可以说：

```text
这也可能和自尊保护有关，但还需要看他是不是只在暴露短板时特别回避。
```

## 4. 禁止把通用知识盖过家庭记忆

如果通用知识和当前家庭记录不一致，优先家庭记录。

## 5. 禁止用专业化、诊断化语言

不要说：

```text
防御机制
逃避型人格
习得性无助
依恋创伤
```

可以改成：

```text
他可能是在给自己留一点退路。
他说不出口时，会先把沟通关掉。
```

---

# 二十七、最低执行标准

日常 Agent 遇到孩子行为时，至少完成以下后台判断：

```text
1. 这个行为具体发生在什么场景？
2. 它发生在开始前、中途、完成后，还是无任务时？
3. 家长有没有把评价当成事实？
4. 这个行为至少有哪 2 个可能解释？
5. 哪个解释最符合孩子旧画像和当前事实？
6. 信息够不够？不够要问哪个关键问题？
7. 这件事适合写成长记录、画像、待观察点，还是不写？
```

---

## 二十八、最终一句话

孩子行为不是答案，而是线索。

同一个行为，在不同孩子、不同家庭、不同时间点里，意义可能完全不同。

> 日常 Agent 要做的不是替家长快速定性孩子，而是在轻回复背后保留多个候选解释，用当前事实和长期画像慢慢逼近更准确的理解。
