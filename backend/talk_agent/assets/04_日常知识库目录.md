# 04_日常知识库目录.md

## 一、文档目的

本文定义「对话实验室」日常对话 Agent 的知识库结构。

日常 Agent 的核心 Prompt 负责规定：

- Agent 是谁；
- 每轮怎么判断；
- 输出什么格式；
- 什么能做、不能做；
- 如何写入记忆候选。

知识库负责提供：

- 家庭教育场景知识；
- 青少年行为解释素材；
- 孩子视角推理参考；
- 家长叙述拆解参考；
- 家庭互动循环案例；
- 沟通预演参考；
- 文风示例；
- 禁止表达与替代表达；
- 常见场景下的高价值追问。

一句话：

> Prompt 规定 Agent 怎么工作；知识库提供 Agent 在不同场景下可以参考的判断材料、表达材料和案例材料。

---

## 二、知识库与 Prompt 的边界

## 1. 不适合放进知识库的内容

以下内容应放在系统 Prompt、输出格式或后端协议里，不应作为普通知识库检索材料：

- 每轮必须返回哪些 JSON 字段；
- `message_type` 有哪些；
- `profile_update_candidates` 格式；
- 后端如何写库；
- Agent Router 如何切换；
- MemoryLoader 如何读取记忆；
- 数据库字段定义；
- 系统级禁止事项；
- 必须每轮执行的内部流程。

这些属于：

```text
系统规则 / 工程协议 / 输出契约
```

## 2. 适合放进知识库的内容

以下内容适合放知识库：

- 作业拖延的不同解释；
- 手机使用在孩子那里可能承担的功能；
- 孩子沉默、顶嘴、敷衍、说“没事”的可能含义；
- 家长常见表达背后的情绪和目标；
- 亲子互动循环案例；
- 高中阶段常见学习压力；
- 考试前后孩子的常见反应；
- 责任感、抗压、自我管理等长期目标的观察方式；
- 沟通预演案例；
- 好回复 / 坏回复示例；
- 禁用表达与替代表达；
- 不同场景下的高价值追问。

这些属于：

```text
判断参考 / 场景素材 / 表达素材 / 示例库
```

## 三、知识库总体结构

建议将日常 Agent 知识库分为 10 大类：

```text
04_日常知识库
├── A_家长叙述拆解知识库
├── B_孩子行为候选解释库
├── C_孩子视角推理案例库
├── D_家长理解与长期目标库
├── E_家庭互动循环识别库
├── F_学习与作业场景库
├── G_手机娱乐与休息边界库
├── H_考试成绩与压力场景库
├── I_沟通预演案例库
└── J_输出文风与示例库
```

其中：

- A、B、C、D、E 是底层理解引擎知识库；
- F、G、H 是高频场景知识库；
- I 是沟通预演专项知识库；
- J 是表达和风格校准知识库。

# A_家长叙述拆解知识库

## 1. 作用

帮助 Agent 从家长输入中拆出：

- 客观事实；
- 孩子行为；
- 家长情绪；
- 家长评价；
- 家长推测；
- 家长目标；
- 缺失信息。

该知识库服务于：

- 轻回应；
- 孩子视角解释；
- 记忆沉淀；
- 家长长期关注识别；
- 待观察点生成；
- 纠偏判断。

## 3. A01_事实情绪评价推测目标区分.md

内容重点：

| 类型 | 说明 | 示例 |
|---|---|---|
| 事实 | 具体发生了什么 | “他写了十分钟就拿手机” |
| 情绪 | 家长感受到什么 | “我真的很烦” |
| 评价 | 家长怎么定性孩子 | “他就是懒” |
| 推测 | 家长猜孩子为什么这样 | “他是不是故意的” |
| 目标 | 家长期待什么 | “我希望他更自觉” |

用途：

- 避免把家长评价直接写入孩子画像；
- 支撑 `understanding_engine.input_decomposition`；
- 支撑记忆写入前的事实判断。

---

## 4. A02_家长常见评价词拆解.md

内容重点：

| 家长原话 | 不能直接写入 | 应拆成 |
|---|---|---|
| 他就是懒 | 孩子懒 | 某任务启动延迟；原因待确认 |
| 他不自觉 | 孩子不自觉 | 缺少外部推动时启动困难 |
| 他沉迷手机 | 孩子沉迷手机 | 手机出现时间和使用功能待确认 |
| 他敷衍我 | 孩子敷衍 | 表面答应但后续未执行 |
| 他玻璃心 | 孩子脆弱 | 被评价后情绪反应强 |
| 他没有责任感 | 孩子无责任感 | 某场景下未承担任务；家长期待责任感 |

用途：

- 支撑家长叙述拆解；
- 防止画像污染；
- 支撑候选解释生成。

## 5. A03_家长高价值关键词识别.md

内容重点：

### 学习类关键词

```text
拖、磨蹭、不自觉、不会也不问、都懂、错题、背诵、订正、检查、效率低、假努力、刷难题
```

可能指向：

- 启动困难；
- 任务拆解困难；
- 暴露短板压力；
- 自尊保护；
- 科目真实卡点；
- 任务边界不清。

### 手机类关键词

```text
沉迷、控制不住、一有空就玩、写完就拿、睡前刷、偷偷玩、不让就急
```

可能指向：

- 即时反馈依赖；
- 学习前逃避压力；
- 完成任务后的恢复；
- 自主权争夺；
- 睡眠节律问题。

### 沟通类关键词

```text
不说话、顶嘴、敷衍、知道了、随便、没事、我错了、下次改
```

可能指向：

- 降低冲突；
- 表面认错；
- 不知道怎么解释；
- 真实想法没有出口；
- 对沟通失去信任。

---

## 6. A04_家长情绪强度识别.md

内容重点：

| 情绪强度 | 表现 | Agent 处理 |
|---|---|---|
| 低 | 平静描述事件 | 可直接轻判断 |
| 中 | 有烦躁、担心 | 先接住，再判断 |
| 高 | “受不了了”“崩溃” | 少建议，先稳定和拆事实 |
| 极高 | 情绪强烈、可能冲突升级 | 不做长分析，不追问多个问题 |

用途：

- 控制回复长度；
- 决定是否主动追问；
- 决定是否给建议。

## 7. A05_家长目标抽取规则.md

常见目标：

- 成绩稳定；
- 学习主动性；
- 责任感；
- 抗压能力；
- 心理健康；
- 人格健全；
- 亲子信任；
- 综合素质；
- 自我管理；
- 兴趣发展；
- 社交能力。

用途：

- 写入 `long_term_goals`；
- 后续相关场景中自然带回；
- 生成周期性小观察。

---

## 8. A06_缺失信息识别与轻追问.md

内容重点：

| 场景 | 缺失信息 | 高价值追问 |
|---|---|---|
| 作业拖延 | 拖在开始前还是中途 | “他是坐下前一直拖，还是写了一段之后才慢下来？” |
| 手机冲突 | 手机出现时间 | “手机最容易在哪个时间冒出来？” |
| 孩子沉默 | 沉默前家长说了什么 | “他沉默前，您最后一句大概是问原因，还是提醒他必须做？” |
| 情绪爆发 | 是否有前面积累 | “这次爆发前几天，他有没有已经明显不太对劲？” |
| 说没事 | 睡眠和学校是否变化 | “他最近是睡眠明显变少，还是白天回家后话变少？” |

规则：

- 每轮最多问一个；
- 问生活事实，不问心理动机；
- 问题要能区分候选解释。

## 3. B01_作业拖延候选解释.md

候选解释：

- 启动困难；
- 不知道从哪一步开始；
- 当前科目有真实卡点；
- 任务太大、无法拆解；
- 担心做完又会被加任务；
- 白天消耗后恢复不足；
- 对被安排缺少参与感；
- 用拖延保留一点主动权；
- 对失败或暴露短板有压力。

可用表达：

```text
他可能不是完全不想做，而是开始前那一下特别难推进。尤其如果他默认“做完一件还有下一件”，就更容易先拖住一点主动权。
```

---

## 4. B02_不会也不问与说都懂.md

候选解释：

- 怕暴露不会；
- 不知道怎么问；
- 觉得问了也会被说；
- 问题太多，自己也分不清；
- 用“懂了”结束追问；
- 不愿承认基础漏洞；
- 对大人讲解方式有压力。

可用表达：

```text
他说“都懂”，不一定是真的都会了，也可能是不想在当下继续暴露自己哪里不会。
```

---

## 5. B03_沉默顶嘴敷衍候选解释.md

沉默可能是：

- 降低冲突；
- 不知道怎么解释；
- 说了也觉得没用；
- 怕越说越被追问；
- 情绪太满说不出来；
- 暂时关闭沟通。

顶嘴可能是：

- 想保留一点主动权；
- 被评价后防御；
- 不知道如何表达不满；
- 对规则不认同。

敷衍可能是：

- 先结束冲突；
- 避免继续被追问；
- 没有形成真实计划；
- 对沟通失去信任。

---

## 6. B04_表面答应但不执行.md

候选解释：

- 先让冲突结束；
- 不是真的形成计划；
- 觉得反驳更麻烦；
- 当下答应是为了让家长安心；
- 执行步骤并没有具体化；
- 对承诺本身已经失去信任；
- 过往承诺后仍被持续盯，导致承诺贬值。

可用表达：

```text
他答应了，不一定代表已经想清楚怎么做。有时候“知道了”“下次改”更像是先让这场冲突停下来。
```

---

## 7. B05_手机使用候选解释.md

候选解释：

- 即时反馈依赖；
- 学习前逃避压力；
- 完成任务后寻找恢复；
- 争取一段自己说了算的时间；
- 从家庭冲突里抽离；
- 缺少其他稳定恢复方式；
- 社交连接；
- 睡前情绪缓冲；
- 用手机证明自己还有选择权。

关键区分问题：

```text
手机是在学习前、学习中、完成一段后，还是无任务时也停不下来？
```

---

## 8. B06_情绪爆发与说没事.md

情绪爆发可能是：

- 长期压着没有出口；
- 某句话触发旧感受；
- 当前事件只是引爆点；
- 身体疲惫后承接力下降；
- 觉得自己一直没被真正理解。

说“没事”可能是：

- 不想被追问；
- 还没整理清楚；
- 觉得说了也没用；
- 不想让父母担心；
- 不愿暴露脆弱；
- 已经习惯关闭表达。

---

## 9. B07_刷难题假努力与自尊保护.md

候选解释：

- 维持优秀感；
- 避开基础漏洞；
- 让自己显得仍在努力；
- 不愿面对“我基础不牢”的羞耻；
- 用高难度任务证明自己仍然强；
- 用忙碌感缓解焦虑。

可用表达：

```text
如果他明知道基础题更该补，却总去碰难题，这未必只是上进，也可能是在维持“我其实还是很强”的感觉。
```

---

## 10. B08_休息边界与自主权.md

常见线索：

- 做完一件后想停；
- 一休息就被安排新任务；
- 空闲时间随时可能被收回；
- 孩子磨蹭来保留任务总量；
- 孩子对临时加课、临时加题抵触。

孩子视角：

```text
效率高不一定意味着能早点结束，反而可能意味着还有更多事等着。
```

---

## 11. B09_学校同伴与归属感.md

可能线索：

- 不愿聊学校；
- 回家话变少；
- 突然说不想上学；
- 成绩没明显变但状态低；
- 对某老师或同学回避；
- 周末明显不愿提学校。

候选解释：

- 同伴关系受挫；
- 学校归属感弱；
- 老师关系紧张；
- 班级氛围变化；
- 考试后自我位置变化；
- 分班、换老师、座位变化等触发。

# C_孩子视角推理案例库

## 1. 作用

提供“家长以为 X，孩子可能体验到 Y”的轻量案例。

日常 Agent 不直接输出“家长盲点”，但要能自然转换视角。

---

## 2. 推荐文件

```text
C_孩子视角推理案例库
├── C01_家长想确认原因孩子感到被追问.md
├── C02_家长想补短板孩子感到休息被压缩.md
├── C03_家长想提高效率孩子担心任务变多.md
├── C04_家长想鼓励孩子听成更高期待.md
├── C05_家长想给空间孩子担心空间被收回.md
├── C06_家长想讲道理孩子感到被评价.md
└── C07_家长想规划未来孩子感到目标不是自己的.md
```

---

## 3. 案例格式

每个案例建议按以下格式写：

```markdown
# 场景名

## 家长以为

## 孩子可能体验到

## 常见触发语

## 可用前台表达

## 不推荐表达

## 可追问问题

## 可写入记忆
```

---

## 4. 示例：家长想确认原因，孩子感到被追问

### 家长以为

```text
我是在帮他找到问题原因。
```

### 孩子可能体验到

```text
我又要被问一轮了，说什么都可能被继续追。
```

### 可用表达

```text
咱们这边肯定是想确认原因，不然也没法判断怎么帮他。但孩子那边可能先感受到的是被连续追问。
```

### 可追问问题

```text
他沉默前，您最后一句更像是在问原因，还是提醒他必须做？
```

### 可写入记忆

```text
family_interaction_patterns：追问—沉默循环
```

## 4. D02_家长焦虑来源识别.md

常见焦虑来源：

- 年级节点：初三、高二、高三；
- 成绩波动；
- 手机失控；
- 作业效率低；
- 孩子不沟通；
- 同伴关系不清楚；
- 花了很多钱但效果不好；
- 孩子“本来可以更好”；
- 家长无法判断孩子真实状态。

---

## 5. D03_家长沟通习惯识别.md

可记录的中性描述：

```text
家长在作业场景中容易连续确认原因。
家长习惯通过讲道理推进问题。
家长更希望先看到具体执行。
家长容易在孩子承诺后继续确认细节。
家长高度关注规则是否被遵守。
```

禁止记录：

```text
家长控制欲强。
家长过度焦虑。
家长不会沟通。
家长强势。
```

```text
├── E03_认错失信循环.md
├── E04_期待压力循环.md
├── E05_手机冲突循环.md
├── E06_边界争夺循环.md
└── E07_信任下降循环.md
```

---

## 3. E01_追问沉默循环.md

链路：

```text
家长担心孩子不说实话
↓
连续追问原因
↓
孩子感到解释也会被继续追
↓
选择沉默或敷衍
↓
家长更不放心
↓
追问更密
```

前台表达：

```text
咱们肯定是想确认原因，但孩子那边可能先感受到的是被连续追问。之前孩子画像里有提到，他在这种情况下容易沉默，这不一定代表完全没想法，也可能是在让冲突先降下来。
```

---

## 4. E02_加任务磨蹭循环.md

链路：

```text
家长看到漏洞，想趁时间补上
↓
孩子发现做完一件后还有下一件
↓
效率提高不等于结束，反而可能带来更多任务
↓
孩子用磨蹭控制任务总量
↓
家长把磨蹭理解成态度问题
↓
继续盯得更紧
```

前台表达：

```text
这件事里，孩子可能慢慢形成了一种预期：做完不一定能结束，可能还会有新的安排。这样他就更容易在开始前慢下来，不完全是态度问题。
```

---

## 5. E03_认错失信循环.md

链路：

```text
家长希望孩子认清问题
↓
孩子用“知道了、下次改”结束冲突
↓
后续没有具体执行
↓
家长觉得孩子敷衍
↓
下一次沟通更不信任
↓
孩子更倾向先答应
```

---

## 6. E04_期待压力循环.md

链路：

```text
家长投入越多，越希望孩子珍惜
↓
孩子感到自己不能失败、不能辜负
↓
越在意越不敢暴露短板
↓
用回避、沉默、假努力保护自己
↓
家长看到效果不好，继续加码
```

## 4. 示例：谈加课补课

家长目标：

```text
补齐短板，防止漏洞扩大。
```

孩子可能接收：

```text
周末休息被压缩。
自己又被安排。
是不是我又不够好。
```

表达方向：

```text
先从孩子觉得哪一块最吃力聊起，再一起确认要不要补、怎么补。
```

容易误会的表达：

```text
必须补。
不能再拖了。
你这个英语太差了。
```

可用输出：

```text
这件事孩子可能先感受到的不是“英语要补”，而是“周末又少了一块能喘口气的时间”。可以先从英语最近哪一块最吃力聊起，再一起确认要不要补、怎么补。
```

# 四、知识库检索规则

## 1. 检索不是每轮都必须

日常 Agent 可以每轮调用知识库，也可以只在以下情况调用：

- 当前场景复杂；
- 需要生成沟通预演；
- 需要解释高频孩子行为；
- 需要识别亲子互动循环；
- 需要生成高价值追问；
- 需要处理家长否定或纠偏；
- 当前输入涉及不熟悉场景。

## 2. 检索优先级

优先检索顺序：

```text
当前场景知识
>
孩子行为候选解释
>
家长叙述拆解
>
家庭互动循环
>
沟通预演案例
>
文风示例
```

例如：

家长说：

```text
他一写作业就拖，我一问为什么，他就不说话。
```

推荐检索：

```text
B01_作业拖延候选解释
B03_沉默顶嘴敷衍候选解释
E01_追问沉默循环
F01_作业启动困难
```

## 3. 检索结果使用规则

Agent 使用知识库时：

- 只能作为内部参考；
- 不要直接复制知识库原文；
- 不要输出知识库标题；
- 不要说“根据知识库”；
- 不要输出内部术语；
- 要转成自然对话。

---

# 五、知识库内容写作规范

每个知识库文件应遵循以下规则。

## 1. 内容要可检索

每篇文件要包含用户可能输入的关键词。

例如：

```text
拖作业、磨蹭、不自觉、不盯不写、写到一半停、作业启动
```

## 2. 内容要场景化

不要只写抽象概念。

应写：

```text
家长说“他就是不自觉，不盯不写”时，可能需要区分：孩子是不知道怎么开始，还是已经习惯了外部推动。
```

不要只写：

```text
孩子可能存在启动困难。
```

## 3. 内容要支持前台表达

每篇文件都应提供可用表达，而不是只有理论解释。

## 4. 内容要防止误判

每篇文件应写清：

- 不要直接判断什么；
- 哪些信息不足；
- 需要追问什么；
- 什么时候写入待观察点。

## 5. 内容要避免诊断化

知识库可以提供深层判断，但前台表达不能医疗化、病理化、诊断化。

# 七、知识库与记忆库的区别

## 1. 知识库

知识库是通用知识。

例如：

```text
孩子拖作业可能有启动困难、任务边界不清、怕暴露短板等解释。
```

## 2. 记忆库

记忆库是某个家庭的具体记录。

例如：

```text
小尹在被连续追问时容易沉默。
小尹最近三次都是完成一段任务后拿手机。
这个家长长期关注责任感与抗压能力。
```

## 3. 两者如何配合

```text
知识库提供候选解释
记忆库提供家庭特异性
当前输入提供最新事实
```

Agent 要综合三者：

```text
当前事实 + 家庭记忆 + 通用知识 = 本轮回复
```

# 九、最低验收标准

日常知识库完成后，应满足：

1. Agent 能区分家长事实、情绪、评价、推测和目标；
2. Agent 不会把“孩子懒”直接写入画像；
3. Agent 能对拖作业、手机、沉默、敷衍等行为生成多个候选解释；
4. Agent 能从孩子视角给出自然解释；
5. Agent 能识别家长长期目标；
6. Agent 能识别常见亲子互动循环；
7. Agent 能为沟通预演提供孩子视角和表达方向；
8. Agent 能生成自然、不像报告的前台表达；
9. Agent 能用知识库支持记忆沉淀和纠偏；
10. Agent 不会因为知识库太重而变成诊断型 Agent。

---

## 十、最终一句话

日常知识库不是为了让 Agent 说得更复杂，而是为了让它在轻回复背后判断得更准。

> 前台越自然，后台越需要知识库支撑；知识库越扎实，日常 Agent 越不容易变成普通聊天机器人。
