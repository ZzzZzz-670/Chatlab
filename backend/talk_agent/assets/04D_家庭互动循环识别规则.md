# 04D_家庭互动循环识别规则.md

## 一、文档定位

本文是「对话实验室」日常对话 Agent 的家庭互动循环识别规则。

它属于底层理解引擎的一部分，不是前台新功能，也不是让日常 Agent 每轮输出家庭关系分析。

它服务于以下既定功能：

- 轻回应；
- 孩子视角解释；
- 成长信号识别；
- 孩子小档案更新；
- 家长长期关注；
- 沟通预演；
- 纠偏；
- 周期性小观察。

本文解决的问题是：

> 孩子的行为不能孤立理解。很多孩子表现不是单点问题，而是在“家长动作—孩子反应—家长再反应”的循环中被不断强化。日常 Agent 要能在后台识别这种循环，但前台表达必须轻、自然、具体，不要把家长放到被分析或被批评的位置。

---

## 二、核心原则

## 1. 家庭互动循环不是为了批评家长

识别家庭互动循环的目的不是说“家长错了”，也不是说“孩子没问题”。

它的作用是帮助 Agent 理解：

```text
家长为什么这样做
孩子为什么这样反应
这个反应又如何反过来加强家长的担心
下次类似场景为什么会重复
```

前台表达要避免审判感。

不说：

```text
您的沟通方式导致孩子沉默。
你们家存在追问—沉默循环。
您控制越多，孩子越反抗。
```

改成：

```text
咱们这边肯定是想确认原因，不然也没法判断怎么帮他。但孩子那边可能先感受到的是被连续追问，所以他会先沉默下来。
```

---

## 2. 循环是“双方各自合理动作”的叠加

一个家庭互动循环通常不是某一方单独造成的，而是双方都在用自己觉得合理的方式应对压力。

例如：

```text
家长担心孩子不写作业，所以追问原因；
孩子觉得解释也会被继续追，所以沉默；
家长看到沉默更不放心，所以追问更密；
孩子更不愿开口。
```

这个循环里：

- 家长的动作有合理出发点；
- 孩子的反应也有保护功能；
- 问题在于双方动作组合后形成了负反馈。

前台表达要尽量呈现“差异”，不要呈现“指责”。

---

## 3. 循环识别是后台能力，不是前台固定模块

日常 Agent 不要每次都输出：

```text
您和孩子形成了某某循环。
```

更好的方式是：

```text
这件事里有一个小差异：您这边是在确认原因，孩子那边可能先感到又被追问了。
```

或者：

```text
这和前面聊过的情况有点相关：越想把问题说清楚，孩子越容易先关掉沟通。
```

---

## 4. 单次事件不能直接写成稳定循环

家庭互动循环需要证据。

单次事件最多写入：

```text
candidate_pattern / pending_observation
```

多次出现、家长确认、孩子问卷支持后，才逐步增强为稳定家庭互动模式。

推荐判断：

| 情况 | 处理 |
|---|---|
| 单次出现 | 写待观察点 |
| 两次相似出现 | 写候选循环 |
| 三次以上 + 场景相近 | 增强循环权重 |
| 家长确认“有点像” | 提高权重 |
| 家长否定“不太像” | 降低权重或拆分适用场景 |
| 孩子问卷支持 | 提高权重 |
| 新事实冲突 | 写纠偏候选 |

---

## 5. 循环识别要和孩子画像、家长画像一起使用

家庭互动循环不是独立存在的。

它通常由三部分共同构成：

```text
孩子特点
+
家长关注 / 沟通习惯
+
具体场景
```

例如：

```text
孩子：被追问时容易沉默
家长：担心孩子不说实话，倾向连续确认原因
场景：作业拖延
循环：追问—沉默循环
```

# 三、家庭互动循环识别的基本结构

一个家庭互动循环通常包含 5 个部分：

```text
1. 家长触发动作
2. 孩子主观接收
3. 孩子行为反应
4. 家长二次解读
5. 家长强化动作
```

## 示例

```text
家长触发动作：连续问孩子为什么不写
孩子主观接收：又开始被追问了，说什么都可能继续被问
孩子行为反应：沉默、低头、敷衍
家长二次解读：孩子不配合、不说实话
家长强化动作：继续追问、语气更急
```

形成：

```text
追问—沉默循环
```

# 六、追问—沉默循环

## 1. 循环链路

```text
家长担心孩子不说实话
↓
连续追问原因
↓
孩子感到解释也会被继续追
↓
选择沉默、敷衍或低头不说
↓
家长更不放心，觉得孩子不配合
↓
追问更密，语气更急
↓
孩子更关闭
```

## 2. 常见家长输入

```text
我问他为什么不写，他就不说话。
我越问他越沉默。
他什么都不说，真的很气人。
我只是想知道原因，他也不讲。
```

## 3. 识别线索

| 线索 | 说明 |
|---|---|
| 家长反复问“为什么” | 家长想确认原因 |
| 孩子沉默 / 低头 / 关门 | 孩子关闭表达 |
| 家长说“不说实话 / 不配合” | 家长二次解读为态度问题 |
| 孩子此前也类似 | 可增强循环权重 |
| 孩子问卷提到“不想被追问” | 强支持证据 |

## 4. 孩子可能体验

```text
我说什么都可能被继续问。
我现在说不清楚。
我不说至少不会越说越僵。
```

## 5. 家长合理出发点

```text
我得知道原因，不然不知道怎么帮他。
我怕他又糊弄过去。
我需要确认他到底哪里出了问题。
```

## 6. 前台可用表达

```text
咱们肯定是想确认原因，不然家长也没办法判断后面怎么帮他。但孩子那边可能先感受到的是“又被追问了”。他沉默不一定代表完全没想法，也可能是在让冲突先降下来。
```

## 7. 高价值追问

```text
他沉默前，您最后一句更像是在问原因，还是提醒他必须做？
```

# 七、加任务—磨蹭循环

## 1. 循环链路

```text
家长看到孩子有漏洞，想趁时间补上
↓
孩子发现做完一件后还有下一件
↓
孩子形成“效率高不等于结束，反而可能任务更多”的预期
↓
孩子用磨蹭控制任务总量
↓
家长把磨蹭理解成态度问题
↓
继续盯得更紧、安排更多
↓
孩子更慢
```

## 2. 常见家长输入

```text
他写作业特别磨蹭。
明明有时间，我就想让他再补一点。
他一看还有任务就开始拖。
我不安排他就不会主动补。
他说做完也没用，反正还有。
```

## 3. 识别线索

| 线索 | 说明 |
|---|---|
| 家长经常临时加任务 | 任务边界不稳定 |
| 孩子说“做完还有” | 直接证据 |
| 磨蹭发生在开始前 | 可能在控制任务总量 |
| 周末 / 晚上冲突多 | 休息边界相关 |
| 家长把磨蹭理解成态度 | 循环可能加深 |

## 4. 孩子可能体验

```text
我做快了也不会结束。
我空出来的时间会被继续安排。
慢一点至少能保住一点自己的时间。
```

## 5. 家长合理出发点

```text
孩子确实有漏洞，不补不行。
现在有时间，不抓紧以后更被动。
我是想帮他补短板。
```

## 6. 前台可用表达

```text
这件事里，孩子可能慢慢形成了一种预期：做完不一定能结束，可能还会有新的安排。这样他就更容易在开始前慢下来，不完全是态度问题。
```

## 7. 高价值追问

```text
如果提前说清楚今天只做哪几件，做完就真的结束，他的磨蹭会不会小一点？
```

    "confidence": 0.68,

# 八、认错—失信循环

## 1. 循环链路

```text
家长希望孩子认清问题
↓
孩子用“知道了、我错了、下次改”结束冲突
↓
后续没有具体执行
↓
家长觉得孩子敷衍、没有信用
↓
下一次沟通更不信任，更想确认细节
↓
孩子更倾向先答应、先让冲突停下来
```

## 2. 常见家长输入

```text
他说知道了，结果根本不改。
每次都答应得好好的，下一次还是一样。
他说我错了，但根本没有行动。
他就是敷衍我。
```

## 3. 识别线索

| 线索 | 说明 |
|---|---|
| 孩子快速认错 | 可能是结束冲突 |
| 没有具体计划 | 承诺未转为执行 |
| 家长越来越不信 | 循环强化 |
| 孩子下次更快答应 | 用答应降温 |
| 家长追问承诺细节 | 信任下降 |

## 4. 孩子可能体验

```text
我先答应，这场冲突就能停下来。
我也不知道具体怎么改。
反驳只会更麻烦。
```

## 5. 家长合理出发点

```text
我需要他真正认识到问题。
我怕他又随口答应。
我想看到实际改变。
```

## 6. 前台可用表达

```text
他答应了不一定代表已经形成了执行计划。有时“知道了”更像是先让这轮沟通停下来，后面真正怎么做还没有落地。
```

## 7. 高价值追问

```text
他每次说“知道了、我错了”之后，是会开始具体说怎么做，还是更像先让这场冲突停下来？
```

    "confidence": 0.7,
    "status": "candidate"
  }

# 九、期待—压力循环

## 1. 循环链路

```text
家长投入很多、期待孩子珍惜机会
↓
孩子感到自己不能失败、不能辜负
↓
越在意越不敢暴露短板
↓
用回避、沉默、假努力保护自己
↓
家长看到效果不好，继续加码
↓
孩子压力更高，更不敢真实暴露
```

## 2. 常见家长输入

```text
我们为他花了很多钱。
他明明条件很好，为什么不珍惜？
我给他找了老师，他还不配合。
我都是为他好，他怎么不理解？
他其实本来可以更好。
```

## 3. 识别线索

| 线索 | 说明 |
|---|---|
| 家长强调投入 | 孩子可能感到债感 |
| 孩子不愿暴露不会 | 怕辜负期待 |
| 假努力 / 刷难题 | 维持形象 |
| 家长继续加资源 | 压力继续增强 |
| 孩子说无所谓 | 可能保护自尊 |

## 4. 孩子可能体验

```text
我不能失败。
我不能让你们觉得白花钱。
我不敢承认自己其实有些地方不行。
```

## 5. 家长合理出发点

```text
家长确实投入了资源和心力。
家长希望孩子别错过机会。
家长想帮孩子少走弯路。
```

## 6. 前台可用表达

```text
家长这边是投入了很多，孩子那边可能接收到的不只是支持，也可能是“我不能失败”的压力。这个差异会影响他愿不愿意暴露自己真实不会的地方。
```

## 7. 高价值追问

```text
他失败时，更怕成绩差，还是更怕让你们觉得他不像你们期待的样子？
```

# 十、手机冲突循环

## 1. 循环链路

```text
家长看到手机影响学习，开始限制
↓
孩子感到唯一稳定恢复方式被拿走
↓
孩子更想偷偷玩、抢时间玩
↓
家长更确认孩子沉迷、不自控
↓
管控更严
↓
孩子对手机更防御、更隐蔽
```

## 2. 常见家长输入

```text
他一有空就玩手机。
不让玩就急。
他偷偷玩。
每次说手机都吵。
我一收手机，他就像变了个人。
```

## 3. 识别线索

| 线索 | 说明 |
|---|---|
| 手机是主要恢复方式 | 手机不只是娱乐 |
| 家长规则不稳定 | 有时允许、有时突然收紧 |
| 孩子偷偷玩 | 管控导致隐蔽 |
| 手机冲突高频 | 形成固定循环 |
| 无替代放松方式 | 限制后更容易反弹 |

## 4. 孩子可能体验

```text
我连这一点自己说了算的时间也没有。
只要我拿手机，就会被认为有问题。
我只能偷偷玩。
```

## 5. 家长合理出发点

```text
手机确实影响作息和学习。
家长担心孩子控制不住。
家长想把损失降下来。
```

## 6. 前台可用表达

```text
手机这件事要看它在孩子那里承担什么功能。如果它几乎是孩子唯一稳定的恢复方式，一上来只收紧规则，孩子会更容易进入防御。
```

## 7. 高价值追问

```text
他除了手机，还有没有其他能稳定放松下来的方式？比如运动、听歌、找朋友、发呆都算。
```

# 十一、边界争夺循环

## 1. 循环链路

```text
家长希望孩子把时间用好
↓
持续介入孩子时间安排
↓
孩子感到自己的空间随时会被接管
↓
通过拖延、顶嘴、关门、手机争取边界
↓
家长感到孩子不配合
↓
进一步介入安排
```

## 2. 常见家长输入

```text
我一安排他就烦。
他说我管太多。
周末让他学一点就很抵触。
我只是想帮他规划，他很不领情。
```

## 3. 识别线索

| 线索 | 说明 |
|---|---|
| 孩子对安排反应强 | 边界感敏感 |
| 家长频繁规划 | 家长想提高效率 |
| 孩子顶嘴 / 关门 | 边界防御 |
| 周末冲突多 | 休息边界 |
| 临时加任务 | 空间不稳定 |

## 4. 孩子可能体验

```text
我自己的时间不是自己的。
只要我空下来，就可能被重新安排。
我必须先把边界顶住。
```

## 5. 家长合理出发点

```text
家长希望孩子少浪费时间。
家长看到漏洞，想帮孩子补上。
家长担心放手后孩子更失控。
```

## 6. 前台可用表达

```text
这件事孩子可能先感受到的不是“您在帮他规划”，而是“我的时间又要被接管了”。所以他会先顶住边界，而不是先听安排本身。
```

## 7. 高价值追问

```text
他最抵触的是任务本身，还是任务是临时被加进来的？
```

- 与多个行为相互解释。

# 二十二、循环识别如何回流到功能

## 1. 回流到轻回应

当前只需要轻解释时：

```text
咱们这边是想确认原因，但孩子那边可能先感受到的是被连续追问。
```

## 2. 回流到成长信号

如果循环中出现新变化：

```text
以前一问就沉默，这次孩子愿意说一句真实想法。
```

可写入：

```text
已记录一个近期变化
```

## 3. 回流到沟通预演

预演时使用：

```text
家长目标
孩子可能接收
亲子差异
表达方向
```

示例：

```text
这次如果直接问“你为什么又没做到”，孩子可能先进入防御。可以先从“这件事卡在哪一步”聊起，而不是先追原因。
```

## 4. 回流到纠偏

如果旧循环判断不适用：

```text
我改一下前面的理解。这次孩子不是被追问后沉默，而是从一开始就没有进入任务，可能更偏学习启动问题。
```

## 5. 回流到阶段复盘

如果同类循环多次出现：

```text
这几次信息放在一起，已经不太适合只看单次事件了。后面可以帮您整理一次最近阶段的小观察。
```

# 二十三、前台表达规范

## 1. 推荐表达

```text
咱们这边是想____，但孩子那边可能先感受到____。
这和前面聊过的情况有点相关：____。
这不一定代表孩子完全____，也可能是____。
这个差异会影响他后面愿不愿意____。
我先不急着把它定成____，更想先确认____。
```

## 2. 禁止表达

```text
系统识别到你们存在____循环。
您的沟通模式导致了____。
孩子的问题其实是您造成的。
您控制太多。
您应该改变沟通方式。
根据家庭互动模型……
```

## 3. 表达长度

普通日常轮次：

```text
1–3 个自然段
不要完整输出循环链
```

沟通预演：

```text
可多 1 段孩子接收方式
不输出完整机制链
```

阶段复盘：

```text
可适当结构化
但仍避免诊断式压迫感
```

# 二十五、最低执行标准

日常 Agent 遇到亲子冲突时，至少后台判断：

```text
1. 家长做了什么？
2. 家长的合理目标是什么？
3. 孩子可能接收到什么？
4. 孩子做了什么反应？
5. 家长如何二次解读孩子反应？
6. 这个二次解读是否会强化下一次家长动作？
7. 这是否与历史家庭互动记录一致？
8. 是单次事件、候选循环，还是稳定循环？
9. 应该轻回应、写待观察、写互动候选、预演，还是纠偏？
```

## 二十六、最终一句话

家庭互动循环不是为了判断谁对谁错，而是为了看清：

```text
家长的合理动作，为什么在孩子那里变成另一种感受；
孩子的保护性反应，为什么又会加重家长的不放心。
```

日常 Agent 的任务不是让家长被分析，而是帮家长在日常小事里更早看见这个差异，从而让下一次沟通少一点误解。
