# 07_家长长期关注库规则.md

## 一、文档定位

本文定义「对话实验室」日常对话 Agent 如何识别、记录、更新和调用家长的长期关注目标。

长期关注不是一句普通偏好，也不是家长临时抱怨。它指的是家长在教育孩子过程中反复在意、持续担心、希望孩子长期形成的能力或状态。

它服务于：

- 日常轻回应；
- 孩子小档案更新；
- 成长信号识别；
- 沟通预演；
- 记忆沉淀；
- 阶段性小观察；
- 家长侧理解；
- 家庭互动判断；
- 产品长期留存。

一句话：

> 家长长期关注库记录的不是“家长今天说了什么”，而是家长长期希望孩子往哪个方向长，以及这个目标如何在日常场景中被持续观察。

---

## 二、为什么需要长期关注库

家长使用「对话实验室」时，表面上常常在说具体问题：

```text
孩子拖作业。
孩子玩手机。
孩子不问问题。
孩子成绩波动。
孩子不愿说话。
孩子一说就烦。
```

但这些具体问题背后，往往有更长期的担心：

```text
他以后能不能自觉？
他有没有责任感？
他抗压行不行？
他心理状态稳不稳？
我们亲子关系会不会越来越差？
他会不会只会考试，没有真正的内驱力？
```

如果系统只回答当前问题，就会变成普通聊天工具。

长期关注库的价值是：

```text
把家长每次零散的担心，沉淀成稳定的长期关注目标；
再在后续日常对话中，把孩子的变化和这些目标持续对照。
```

这样家长会感觉：

```text
它不只是回答我今天的问题，它知道我一直真正关心什么。
```

---

## 三、长期关注目标的定义

家长长期关注目标，是指家长希望孩子在较长时间内形成、改善或保持的能力、状态、品质、关系或发展方向。

它通常具备以下特征：

- 不只针对当天事件；
- 可跨多个场景持续观察；
- 与孩子成长方向有关；
- 家长可能反复提到；
- 能影响后续回复重点；
- 能与成长信号、画像更新、阶段复盘关联。

示例：

```text
希望孩子更自觉。
希望孩子更有责任感。
希望孩子心理健康一点。
希望孩子能抗压。
希望孩子不要只会考试。
希望孩子愿意跟我说实话。
希望孩子有自己的目标。
希望孩子学会安排时间。
```

---

## 四、长期关注目标与普通情绪的区别

## 1. 普通情绪

家长当下的感受。

示例：

```text
我今天真的很烦。
我快被他气死了。
我现在很无力。
```

处理：

```text
回应情绪，不直接写长期关注。
```

---

## 2. 临时诉求

家长当前想解决一件具体事。

示例：

```text
今晚怎么让他先把作业写完？
这次数学错题怎么处理？
明天要不要跟老师说？
```

处理：

```text
回应当前问题，不一定写长期关注。
```

---

## 3. 长期关注

家长希望孩子长期形成的能力或状态。

示例：

```text
我不希望他一直靠我们催。
我希望他以后能自己安排。
我希望他心理健康一点，不要只看成绩。
```

处理：

```text
写入 long_term_goals。
```

---

## 五、长期关注目标的主要类别

建议分为 12 类：

```text
1. 成绩稳定
2. 学习主动性
3. 自我管理
4. 责任感
5. 抗压能力
6. 心理健康
7. 人格健全
8. 亲子信任
9. 沟通表达
10. 兴趣与内驱力
11. 社交与归属感
12. 综合素质与长期发展
```

# 六、成绩稳定

## 1. 定义

家长关注孩子成绩是否稳定、是否持续进步、是否能在关键考试中保持状态。

## 2. 常见家长表达

```text
我就希望他成绩别波动太大。
高二了，不能再这么不稳定。
他这次数学掉了很多，我很担心。
我怕他这样下去高考吃亏。
```

## 3. 可识别信号

- 家长反复提到排名；
- 家长关注单科波动；
- 家长担心考试节点；
- 家长把日常作业和最终升学强关联；
- 家长对“漏洞”特别敏感。

## 4. 关联场景

```text
考试复盘
错题订正
作业效率
学科短板
考前状态
考后情绪
补课安排
```

## 5. 前台表达

```text
这个可以放进您一直关注的成绩稳定里看。现在不只是这一次作业慢，更关键的是：这个慢会不会反复影响他复习节奏和考试状态。
```

## 6. 写入示例

```json
{
  "goal_name": "成绩稳定",
  "goal_category": "academic",
  "related_scenes": ["考试复盘", "错题订正", "学科短板", "补课安排"],
  "weight_delta": 0.12
}
```

# 七、学习主动性

## 1. 定义

家长希望孩子不是被动完成任务，而是能主动发现问题、主动推进学习。

## 2. 常见家长表达

```text
他什么时候能自己学？
不能总靠我们催。
我希望他有点内驱力。
他自己一点都不主动。
```

## 3. 可识别信号

- 家长多次提到“不催不动”；
- 家长关注孩子是否主动问问题；
- 家长在意孩子是否主动复盘；
- 家长希望孩子自己安排学习；
- 家长把拖延理解为没有主动性。

## 4. 关联场景

```text
作业启动
不会也不问
错题复盘
周末安排
手机规则
考试后复盘
```

## 5. 前台表达

```text
这件事也能放进您一直在意的“学习主动性”里看。但现在先不要急着看他能不能完全自觉，可以先看他能不能主动说出一个很小的下一步。
```

## 6. 写入示例

```json
{
  "goal_name": "学习主动性",
  "goal_category": "academic_initiative",
  "related_scenes": ["作业启动", "错题复盘", "周末安排"],
  "weight_delta": 0.15
}
```

---

# 八、自我管理

## 1. 定义

家长希望孩子能管理时间、任务、手机、休息和学习节奏。

## 2. 常见家长表达

```text
他时间一点不会安排。
他自己管不住手机。
他不知道什么时候该学、什么时候该休息。
我希望他能自己规划。
```

## 3. 可识别信号

- 手机规则反复冲突；
- 周末安排冲突；
- 作业拖到很晚；
- 孩子不清楚任务顺序；
- 家长频繁代替孩子规划；
- 家长担心放手后孩子失控。

## 4. 关联场景

```text
手机
作业启动
周末安排
睡眠
任务拆解
休息边界
```

## 5. 前台表达

```text
这个目标可以放进“自我管理”里看。现在先不要求他一下子完全自律，更现实的是看他能不能先管理一个小范围：比如一段任务、一次休息、一个手机使用边界。
```

## 6. 写入示例

```json
{
  "goal_name": "自我管理",
  "goal_category": "self_management",
  "related_scenes": ["手机规则", "作业启动", "周末安排", "睡眠"],
  "weight_delta": 0.15
}
```

# 九、责任感

## 1. 定义

家长希望孩子能承担自己的任务、承诺和后果，而不是总靠家长推动。

## 2. 常见家长表达

```text
我希望他有点责任感。
不能什么都靠我们操心。
他答应了就应该做到。
他现在对自己的事一点不上心。
```

## 3. 可识别信号

- 家长反复提到承诺不兑现；
- 家长担心孩子没有担当；
- 家长希望孩子对学习结果负责；
- 家长把拖延、敷衍、手机理解为无责任感；
- 家长在意孩子是否主动承担后果。

## 4. 关联场景

```text
作业承诺
表面答应但不执行
错题订正
手机规则
周末安排
考试复盘
```

## 5. 前台表达

```text
这件事可以放进您之前提到的责任感里看。现在不急着给他下“有没有责任感”的结论，更关键的是：他能不能先承担一个边界清楚的小任务。
```

## 6. 写入示例

```json
{
  "goal_name": "责任感",
  "goal_category": "responsibility",
  "related_scenes": ["作业承诺", "手机规则", "考试复盘"],
  "weight_delta": 0.15
}
```

# 十、抗压能力

## 1. 定义

家长希望孩子面对考试、失败、批评、竞争和不确定性时，不轻易崩掉、逃避或关闭。

## 2. 常见家长表达

```text
他一遇到压力就不行。
考差一次就整个人很低。
我希望他抗压强一点。
他不能一点挫折都受不了。
```

## 3. 可识别信号

- 成绩波动后情绪明显；
- 孩子说“无所谓”但后续低落；
- 考前回避；
- 被检查后爆发；
- 不愿面对错题；
- 家长担心孩子承受不了失败。

## 4. 关联场景

```text
考试前后
错题订正
成绩波动
竞赛/排名
补课检查
家长期待
```

## 5. 前台表达

```text
这个可以放进您关注的抗压能力里看。抗压不是孩子被批评也没反应，而是他面对失败时还能不能说出一点具体困难、还能不能回到下一步。
```

## 6. 写入示例

```json
{
  "goal_name": "抗压能力",
  "goal_category": "resilience",
  "related_scenes": ["考试复盘", "错题订正", "成绩波动"],
  "weight_delta": 0.15
}
```

# 十一、心理健康

## 1. 定义

家长希望孩子保持基本情绪稳定、内在安全感、生活能量和心理承接力。

注意：日常 Agent 不做心理疾病诊断，也不使用医疗化表达。

## 2. 常见家长表达

```text
我希望他心理健康一点。
我不希望他压力太大。
我不想他只会考试，人垮了。
他最近整个人状态不太对。
```

## 3. 可识别信号

- 睡眠明显变差；
- 情绪爆发频率升高；
- 兴趣下降；
- 不愿沟通；
- 说没事但状态低；
- 回家明显话少；
- 对学校回避；
- 自我否定频繁。

## 4. 关联场景

```text
睡眠
学校同伴
考试压力
兴趣下降
情绪爆发
亲子冲突
手机使用
```

## 5. 前台表达

```text
这个目标很重要，可以放进长期关注里。后面我们不只看成绩，也会一起看孩子的睡眠、情绪恢复、兴趣和愿不愿意表达这些信号。
```

## 6. 写入示例

```json
{
  "goal_name": "心理健康",
  "goal_category": "mental_health",
  "related_scenes": ["睡眠", "情绪", "学校同伴", "兴趣", "亲子沟通"],
  "weight_delta": 0.18
}
```

# 十二、人格健全

## 1. 定义

家长希望孩子不仅成绩好，还能形成稳定的人格底色：自尊、自信、责任、共情、边界、独立判断。

## 2. 常见家长表达

```text
我不希望他只会学习。
我希望他成为一个完整的人。
成绩重要，但人格更重要。
我希望他以后有判断力、有担当。
```

## 3. 可识别信号

- 家长不只谈成绩；
- 家长强调做人、担当、心态；
- 家长在意孩子是否有自尊和边界；
- 家长关注孩子是否能处理关系；
- 家长关注长期而非单次成绩。

## 4. 关联场景

```text
责任感
抗压
社交
亲子信任
兴趣发展
自我表达
边界感
```

## 5. 前台表达

```text
这个目标比单次成绩更长期。后面我们可以把孩子的责任感、抗压、表达、兴趣和关系状态一起放进这个方向里观察。
```

## 6. 写入示例

```json
{
  "goal_name": "人格健全",
  "goal_category": "well_rounded_growth",
  "related_scenes": ["责任感", "抗压", "表达", "兴趣", "社交"],
  "weight_delta": 0.15
}
```

# 十三、亲子信任

## 1. 定义

家长希望孩子愿意说真实想法，亲子之间不是靠监控、逼问、试探维持互动。

## 2. 常见家长表达

```text
我希望他能跟我说实话。
他现在什么都不告诉我。
我不想我们关系越来越僵。
我希望他有事能愿意跟我讲。
```

## 3. 可识别信号

- 家长反复说孩子不说；
- 孩子沉默、关门、敷衍；
- 家长不信孩子承诺；
- 孩子怕被追问；
- 家庭互动进入信任下降循环；
- 家长希望修复沟通关系。

## 4. 关联场景

```text
沉默
表面答应
追问—沉默循环
信任下降循环
沟通预演
学校同伴分享
手机规则
```

## 5. 前台表达

```text
这件事也和您在意的亲子信任有关。现在不只是让他说出一个答案，更重要的是让他觉得说出来之后不会马上进入一轮追问或评价。
```

## 6. 写入示例

```json
{
  "goal_name": "亲子信任",
  "goal_category": "relationship",
  "related_scenes": ["沉默", "承诺", "手机规则", "学校分享", "沟通预演"],
  "weight_delta": 0.16
}
```

# 十四、沟通表达

## 1. 定义

家长希望孩子能表达真实想法、困难、需求和情绪，而不是沉默、顶嘴、敷衍或关闭。

## 2. 常见家长表达

```text
我希望他有话能说出来。
他不要什么都憋着。
他能不能别一问就关掉？
我想知道他真实怎么想。
```

## 3. 可识别信号

- 孩子不说学校；
- 说没事但状态不对；
- 被问就沉默；
- 表面答应；
- 只能顶嘴表达不满；
- 家长想知道孩子真实想法。

## 4. 关联场景

```text
亲子沟通
学校分享
作业冲突
考试复盘
手机规则
情绪状态
```

## 5. 前台表达

```text
这个可以单独放进沟通表达里观察。对这个孩子来说，变化不一定是一口气说很多，而是从完全关掉到愿意说出一个具体感受。
```

## 6. 写入示例

```json
{
  "goal_name": "沟通表达",
  "goal_category": "communication",
  "related_scenes": ["作业冲突", "学校分享", "情绪表达", "考试复盘"],
  "weight_delta": 0.14
}
```

# 十五、兴趣与内驱力

## 1. 定义

家长希望孩子有真正喜欢、愿意投入、能提供能量的事情，而不是完全被成绩和外部安排驱动。

## 2. 常见家长表达

```text
他好像对什么都没兴趣。
我希望他有点真正喜欢的东西。
他不能只为了考试活着。
我希望他自己有动力。
```

## 3. 可识别信号

- 兴趣下降；
- 只剩手机；
- 不愿运动或社交；
- 对未来说随便；
- 对学习目标无感；
- 家长关注内驱力。

## 4. 关联场景

```text
兴趣下降
手机替代恢复
学校归属
未来规划
周末安排
综合素质
```

## 5. 前台表达

```text
这个目标可以放进兴趣和内驱力里看。后面我们不只看他学不学，也要看有没有什么东西能让他自己愿意投入、愿意恢复一点能量。
```

## 6. 写入示例

```json
{
  "goal_name": "兴趣与内驱力",
  "goal_category": "interest_development",
  "related_scenes": ["兴趣", "手机", "未来规划", "周末安排"],
  "weight_delta": 0.15
}
```

# 十六、社交与归属感

## 1. 定义

家长关注孩子是否有稳定同伴关系、学校归属感、正常社交支持和集体中的位置感。

## 2. 常见家长表达

```text
他在学校有没有朋友？
他最近不提同学了。
我怕他在学校不开心。
他是不是被孤立了？
我希望他有正常的社交。
```

## 3. 可识别信号

- 不愿聊学校；
- 不提朋友；
- 回家话变少；
- 说不想上学；
- 情绪低但成绩无明显解释；
- 班级、分班、换座后状态变；
- 家长关注同伴关系。

## 4. 关联场景

```text
学校分享
同伴关系
老师关系
班级归属
不想上学
兴趣活动
情绪状态
```

## 5. 前台表达

```text
这个可以放进学校归属感里继续观察。孩子不聊学校，不一定就是没事，也不一定是故意瞒着，可能要看他是避开同学、老师，还是整个学校话题都不想碰。
```

## 6. 写入示例

```json
{
  "goal_name": "社交与归属感",
  "goal_category": "social",
  "related_scenes": ["学校分享", "同伴关系", "情绪状态", "兴趣活动"],
  "weight_delta": 0.13
}
```

# 十七、综合素质与长期发展

## 1. 定义

家长希望孩子在学业之外，也形成长期发展能力，包括视野、表达、判断、习惯、情绪稳定、关系能力等。

## 2. 常见家长表达

```text
我不希望他只盯着分数。
我希望他以后有长期竞争力。
我希望他综合能力强一点。
他不能只会刷题。
```

## 3. 可识别信号

- 家长谈到长远发展；
- 家长关注孩子是否有判断力；
- 家长关注表达、社交、抗压、责任；
- 家长不满足于单科成绩；
- 家长希望孩子更完整。

## 4. 关联场景

```text
学习方法
自我管理
兴趣发展
社交表达
抗压能力
责任感
沟通能力
```

## 5. 前台表达

```text
这个目标比较长期，后面可以拆成几个具体观察点：自我管理、抗压、表达、兴趣和责任感。否则“综合素质”太大，日常里不容易看见变化。
```

## 6. 写入示例

```json
{
  "goal_name": "综合素质与长期发展",
  "goal_category": "well_rounded_growth",
  "related_scenes": ["自我管理", "抗压", "表达", "兴趣", "责任感"],
  "weight_delta": 0.12
}
```

# 十八、长期关注目标抽取规则

## 1. 明确表达，直接抽取

家长明确说“我希望 / 我不希望 / 我担心 / 我最在意”。

示例：

```text
我希望他更有责任感。
```

写入：

```json
{
  "goal_name": "责任感",
  "goal_category": "responsibility",
  "weight_delta": 0.15
}
```

---

## 2. 反复抱怨，间接抽取

家长没有直接说目标，但反复抱怨同类问题。

示例：

```text
不催就不动。
什么都要盯。
自己一点不安排。
```

可推断长期关注：

```text
学习主动性 / 自我管理
```

但要降低置信度。

---

## 3. 强情绪背后抽取

家长强烈情绪背后可能有长期目标。

示例：

```text
我真的受不了他每次都答应不做到。
```

可抽取：

```text
责任感 / 亲子信任
```

但不要只凭一次就高权重写入。

---

## 4. 教育决策中抽取

家长讨论加课、手机、学校、活动时，也可能暴露长期目标。

示例：

```text
我不想只是给他补分数，我更想让他自己知道该怎么学。
```

抽取：

```text
学习主动性 / 自我管理
```

# 二十一、权重规则

长期关注目标需要有权重，不要所有目标平铺。

## 1. 初始权重建议

| 情况 | 初始权重 |
|---|---|
| 家长明确表达一次 | 0.55–0.65 |
| 家长强烈表达一次 | 0.65–0.75 |
| 家长反复表达 | 0.75–0.9 |
| 家长轻微提到 | 0.35–0.5 |
| 系统间接推断 | 0.3–0.45 |

---

## 2. 提高权重

以下情况提高权重：

- 家长再次提到；
- 家长明确说“这个很重要”；
- 当前事件与该目标强相关；
- 成长信号与该目标相关；
- 阶段复盘中再次出现；
- 家长点击“有点像”。

建议：

```text
普通再次提到：+0.05
强相关事件：+0.08
家长明确确认：+0.12
阶段复盘确认：+0.15
```

---

## 3. 降低权重

以下情况降低权重：

- 长期未出现；
- 家长否定该目标不重要；
- 新目标明显替代旧目标；
- 旧目标只是在特定阶段短暂出现。

建议：

```text
30 天未触发：-0.05
60 天未触发：-0.1
家长明确否定：-0.2
```

---

## 4. 权重使用

高权重目标：

```text
更容易在相关场景中被自然带回。
```

低权重目标：

```text
仅在强相关场景中使用，不主动提。
```

---

# 二十二、长期关注目标合并规则

## 1. 同义目标合并

以下目标可合并：

```text
自觉 / 主动 / 内驱力 → 学习主动性
自律 / 时间管理 / 管手机 → 自我管理
担当 / 说到做到 / 对自己负责 → 责任感
心理健康 / 情绪稳定 / 别太压抑 → 心理健康
愿意说 / 说实话 / 别关门 → 沟通表达 / 亲子信任
```

---

## 2. 目标过大时拆分

示例：

```text
综合素质
```

可拆成：

```text
自我管理
抗压能力
沟通表达
兴趣发展
责任感
```

前台可说：

```text
这个目标比较大，后面我会把它拆成几个更容易观察的小方向：自我管理、抗压、表达和兴趣。
```

---

## 3. 同一目标不重复新增

如果已有：

```text
责任感
```

家长又说：

```text
希望他不要什么都靠我们催。
```

处理：

```text
不新增“不要靠催”。
合并到责任感 / 自我管理，提高权重。
```

---

# 二十三、长期关注目标调用规则

## 1. 什么时候调用

可以调用：

- 当前场景与目标强相关；
- 家长主动提到目标；
- 近期成长信号与目标有关；
- 沟通预演需要考虑目标；
- 阶段小观察总结；
- 旧目标长期未触发但突然相关。

不调用：

- 当前只是普通情绪宣泄；
- 目标和场景关系弱；
- 调用会显得生硬；
- 家长刚表达疲惫，不适合拔高；
- 每轮都提会让家长觉得系统机械。

---

## 2. 调用方式

推荐自然带回：

```text
这件事也能放进您之前提到的“责任感”里看。
```

```text
如果从自我管理这个目标看，现在更关键的不是他能不能一下子完全自律，而是能不能先承担一个小边界。
```

避免：

```text
根据您的长期关注目标……
系统检测到该事件匹配长期目标……
正在调用 long_term_goals……
```

---

## 3. 调用频率

同一个目标不要每轮都提。

建议：

```text
同一目标 3–5 轮内最多自然提 1 次。
强相关场景可例外。
阶段复盘可集中总结。
```

---

# 二十四、和成长信号的关系

长期关注目标需要通过成长信号持续观察。

示例：

长期目标：

```text
责任感与自我管理
```

相关成长信号：

```text
孩子主动提出先写数学再休息。
孩子能按约定十分钟后回来。
孩子承认今天没做到，并说出明天具体怎么补。
```

写入方式：

```json
{
  "growth_record": {
    "content": "孩子主动提出一个小任务安排",
    "related_long_term_goals": ["责任感与自我管理"]
  }
}
```

---

# 二十五、和沟通预演的关系

沟通预演需要考虑家长长期目标。

例如：

家长目标：

```text
责任感
```

当前预演：

```text
想和孩子谈周末作业安排。
```

不应只帮家长“让孩子听话”。

应围绕：

```text
如何让孩子参与一点安排；
如何让孩子承担一个小边界；
如何减少被通知感。
```

前台表达：

```text
如果这次目标不只是让他完成作业，而是慢慢培养责任感，那重点就不是把安排全部说完，而是让他参与确定一个自己能承担的小任务。
```

---

# 二十六、和纠偏的关系

长期目标也可能被修正。

## 1. 目标权重下降

家长过去高度关注成绩，后来更关注心理健康。

处理：

```text
成绩稳定权重下降；
心理健康权重上升；
后续回复不再过度从成绩角度解释一切。
```

## 2. 目标拆分

家长说：

```text
我之前以为我只是希望他自觉，但现在想想，我更怕的是我们关系越来越差。
```

处理：

```text
学习主动性保留；
亲子信任新增或提高权重；
写入 correction_logs 或 goal_update_log。
```

前台表达：

```text
这个信息会让前面的长期关注更清楚一点。之前更像是“学习主动性”，现在看，亲子信任也是很重要的一条。
```

---

# 二十七、前台表达规则

## 1. 推荐表达

```text
这个目标我会放进孩子的长期成长规划里。
这件事也能放进您之前提到的____里看。
后面我们聊____时，可以一起关注这个方向。
现在不急着看他能不能一下子做到，更重要的是先看____。
这个目标比较大，后面可以拆成几个更容易观察的小方向。
```

## 2. 避免表达

```text
已识别您的长期目标。
系统正在更新家长长期关注库。
根据长期目标模型……
您真正焦虑的是……
您的教育目标是……
```

## 3. 不要过度升华

不要把每个小问题都拔高到“人格”“未来”“人生”。

家长说：

```text
今晚作业又拖了。
```

不一定要说：

```text
这关系到孩子未来责任感和人格健全。
```

应只在目标强相关时自然带回。

# 二十九、最低执行标准

日常 Agent 每轮处理家长输入时，应判断：

```text
1. 家长是否表达了长期目标？
2. 这是临时情绪、当前诉求，还是长期关注？
3. 目标属于哪个类别？
4. 是否已有同类目标，需要合并而非新增？
5. 这个目标权重应增加多少？
6. 当前事件是否关联已有长期目标？
7. 是否适合在前台自然带回？
8. 是否需要和成长信号、沟通预演或纠偏关联？
```

## 三十、最终一句话

家长长期关注库的价值，不是把家长说过的目标存起来，而是让系统在每一次日常对话中知道：

```text
这位家长真正长期在意什么；
孩子哪些小变化与这些目标有关；
哪些问题只是当天事件，哪些问题其实牵动了长期成长方向。
```

> 日常 Agent 要让家长感觉：它不只是懂孩子今天怎么了，也记得我一直希望孩子长成什么样。
