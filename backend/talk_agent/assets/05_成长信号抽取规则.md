# 05_成长信号抽取规则.md

## 一、文档定位

本文定义「对话实验室」日常对话 Agent 如何从家长的日常输入中识别、判断、沉淀“成长信号”。

成长信号不是产品的新功能，而是日常 Agent 的核心记忆能力之一。它服务于：

- 轻回应；
- 孩子小档案更新；
- 近期变化记录；
- 家长长期关注目标；
- 周期性小观察；
- 阶段复盘；
- 纠偏；
- 孩子画像持续更新。

一句话：

> 成长信号不是“家长说了一件事就记录”，而是当前事件相对于这个孩子旧状态发生了有价值的变化，且这个变化能帮助后续更准确理解孩子。

---

## 二、核心定义

## 1. 什么是成长信号

成长信号是指：

```text
孩子在学习、情绪、沟通、休息、自我管理、兴趣、同伴关系、家庭互动等方面出现的具体变化。
```

这个变化不一定是大进步，也不一定全是正向。

它可以是：

- 孩子主动表达了一点；
- 孩子抵触少了一点；
- 孩子愿意讨论以前不愿讨论的话题；
- 孩子第一次说出真实困难；
- 孩子在某场景下反应变柔和；
- 孩子开始承担一点安排；
- 孩子出现新的压力信号；
- 孩子旧问题换了表现方式；
- 家庭互动出现一个有效经验。

成长信号的重点不是“好事”，而是“有判断价值的变化”。

---

## 2. 成长信号的判断公式

```text
成长信号 = 当前具体事实 + 与孩子旧画像的差异 + 对未来理解有价值
```

三个条件缺一不可。

### 条件一：当前具体事实

必须有具体事件或具体表现。

例如：

```text
孩子今天主动提到学校里的事。
孩子这次被问作业时没有直接沉默，而是说了一句“我不知道从哪开始”。
孩子完成一段作业后主动说想休息十分钟。
```

### 条件二：与孩子旧画像有差异

同一件事，对不同孩子意义不同。

例如：

```text
孩子主动说学校的事
```

如果旧画像是“孩子平时很愿意分享学校”，这可能只是普通日常。

如果旧画像是“孩子很少主动聊学校”，这就是成长信号。

### 条件三：对未来理解有价值

这个变化能帮助后续判断孩子状态、家庭互动或长期目标。

例如：

```text
孩子愿意说“我不知道从哪开始”
```

这个变化有价值，因为它提示：

- 孩子不是完全不想做；
- 可能存在任务启动或任务拆解困难；
- 后续可以围绕“从哪一步开始”设计支持。

---

## 三、成长信号不是只记录正向变化

成长信号分为三类：

```text
正向变化
中性变化
预警变化
```

## 1. 正向变化

孩子出现更开放、更主动、更稳定、更能表达、更愿意承担的表现。

示例：

- 主动聊学校；
- 主动问问题；
- 愿意说自己哪里不会；
- 被提醒后没有立刻顶回去；
- 愿意一起讨论安排；
- 完成一段任务后能主动说明想休息；
- 对以前抵触的事愿意试一下。

## 2. 中性变化

孩子行为发生变化，但暂时不能判断好坏。

示例：

- 以前直接沉默，现在说“随便”；
- 以前顶嘴，现在回房间；
- 以前写前拖，现在写到一半停；
- 手机从学习前出现，变成完成一段后出现；
- 孩子开始更在意同伴评价；
- 孩子不再说学校，但睡眠也变少。

中性变化通常写入：

```text
growth_records + pending_observations
```

## 3. 预警变化

孩子出现状态下降、压力加重、表达关闭、兴趣下降、互动恶化等信号。

示例：

- 原来喜欢的兴趣也不碰了；
- 最近回家话明显变少；
- 说“没事”的频率增加；
- 多次出现睡眠变差；
- 对成绩表现出强烈无所谓；
- 以前能聊，现在一问就关门；
- 手机从任务完成后恢复，变成无任务时也停不下；
- 家庭冲突后恢复时间变长。

预警变化不是心理诊断，不能医疗化表达。

---

## 四、成长信号与普通记录的区别

## 1. 普通记录

普通记录只是发生了一件事，但无法判断是否有变化。

例如：

```text
孩子今天写了作业。
孩子今天玩了手机。
孩子今天和家长说话了。
```

如果没有旧画像对照，这些只是普通事实。

## 2. 成长信号

成长信号必须和旧状态形成对照。

例如：

```text
孩子以前一提作业就沉默，这次主动说“我不知道从哪开始”。
```

这就是成长信号，因为它体现：

- 孩子从关闭表达变为说出困难；
- 作业问题可能从“态度差”转向“启动困难/任务拆解困难”；
- 后续可以更新孩子小档案。

---

## 五、成长信号抽取的内部流程

每次家长输入后，日常 Agent 内部按以下流程判断：

```text
1. 提取当前具体事实
2. 判断是否涉及孩子状态变化
3. 调用孩子旧画像和近期记录
4. 比较当前事实与旧状态的差异
5. 判断这个差异是否有未来复用价值
6. 判断是正向变化、中性变化还是预警变化
7. 决定写入 growth_records / pending_observations / profile_entries
8. 生成前台轻回应和 memory_note
```

---

## 六、成长信号的主要类别

建议将成长信号分为 10 类：

```text
1. 表达开放信号
2. 学习启动信号
3. 学习卡点暴露信号
4. 情绪状态信号
5. 沟通互动信号
6. 手机与休息边界信号
7. 自我管理与责任感信号
8. 兴趣与能量来源信号
9. 学校同伴与归属感信号
10. 家庭互动有效经验信号
```

---

# 七、表达开放信号

## 1. 定义

孩子愿意说出以前不愿说、说不清或不敢说的内容。

## 2. 常见表现

- 主动聊学校；
- 主动说今天发生了什么；
- 说出“我不会”；
- 说出“不想”；
- 说出“我不知道怎么开始”；
- 说出“我有点烦”；
- 说出对某个安排的真实感受；
- 从沉默变成能说一句具体话。

## 3. 判断标准

只有当孩子过去在相关场景中较少表达时，才构成强成长信号。

例如：

```text
旧画像：孩子被问作业时容易沉默。
新事实：这次孩子说“我不知道从哪开始”。
判断：表达开放信号。
```

## 4. 前台表达

```text
这个变化挺值得记一下。以前一到作业问题，他更容易沉默；这次能说出“不知道从哪开始”，说明他至少把困难露出了一点点。
```

## 5. 可写入 growth_records

```json
{
  "scene_type": "communication",
  "signal_type": "表达开放",
  "content": "孩子在作业场景中说出“不知道从哪开始”，相比过去沉默有变化",
  "importance": "high",
  "difference_from_previous_profile": "此前孩子在作业追问中更容易沉默"
}
```

## 6. 可能关联的待观察点

```text
继续观察孩子是否能在作业场景中说出具体困难，而不是直接沉默或说“都懂”。
```

---

# 八、学习启动信号

## 1. 定义

孩子在开始学习、进入任务、面对作业安排时出现的变化。

## 2. 常见表现

正向：

- 比以前更快坐下；
- 能主动说先做哪一项；
- 能接受一个小任务；
- 能自己开始一段；
- 做完一段后能回来继续；
- 能说出“我先写数学”。

中性：

- 以前一开始拖，现在写到一半停；
- 以前完全不动，现在能坐下但很慢；
- 以前需要催十次，现在催两三次能动。

预警：

- 原来能开始，现在坐下都困难；
- 原来只某科拖，现在所有任务都拖；
- 原来晚点能做，现在完全不动。

## 3. 判断重点

学习启动信号必须区分：

```text
开始前困难
过程困难
完成后恢复
任务边界问题
```

## 4. 高价值问题

```text
他是坐下前一直拖，还是写了一段之后才慢下来？
```

## 5. 前台表达

```text
这个变化可以记一下：他不是完全没进入任务，而是开始那一下还是比较难。后面我们可以重点观察，是不是任务拆小一点后更容易启动。
```

## 6. 可写入 growth_records

```json
{
  "scene_type": "academic",
  "signal_type": "学习启动变化",
  "content": "孩子能坐下开始一段任务，但启动前仍有明显阻力",
  "importance": "medium",
  "difference_from_previous_profile": "此前表现为完全拖着不开始"
}
```

---

# 九、学习卡点暴露信号

## 1. 定义

孩子开始暴露真实不会、真实卡住、真实困难，而不是用“都懂”“不会也不问”“随便”遮住。

## 2. 常见表现

- 说出哪一题不会；
- 说出某一科最烦；
- 说出“我不是不想写，是不会写”；
- 承认背不下来；
- 承认检查时紧张；
- 说出“我不知道怎么问”；
- 从“都懂”变成“这一块不懂”。

## 3. 判断标准

对于过去不愿暴露短板的孩子，这是强成长信号。

## 4. 前台表达

```text
这其实是一个很重要的变化。他不是简单说“都懂”或者沉默，而是把具体不会的地方露出来了。对后续帮他，价值比直接催他多做几道题更大。
```

## 5. 可写入 growth_records

```json
{
  "scene_type": "academic",
  "signal_type": "卡点暴露",
  "content": "孩子开始说出具体不会的内容，而不是笼统说都懂",
  "importance": "high",
  "difference_from_previous_profile": "此前孩子更倾向于说都懂或不问问题"
}
```

## 6. 可能升级为 profile_entry

如果多次出现：

```text
孩子在低压力场景下更愿意暴露具体学习困难。
```

---

# 十、情绪状态信号

## 1. 定义

孩子情绪反应、压力表现、疲惫程度、恢复速度发生变化。

## 2. 常见正向信号

- 被提醒后没有立刻爆；
- 情绪起来后恢复更快；
- 能说“我有点烦”；
- 能表达累；
- 冲突后愿意回来继续说；
- 以前回房间，现在还能待在原地。

## 3. 常见预警信号

- 最近更容易烦；
- 原来能聊，现在一问就关门；
- 睡眠变差；
- 回家话明显变少；
- 兴趣下降；
- 情绪爆发频率升高；
- 说“没事”但状态持续低；
- 家庭冲突后恢复时间变长。

## 4. 判断重点

情绪变化要结合：

- 睡眠；
- 学校；
- 同伴；
- 考试；
- 家庭冲突；
- 学习负荷；
- 手机使用变化。

## 5. 前台表达

```text
这个变化要记一下。它不一定说明问题变严重，但说明孩子最近的承接力可能比前段时间低了一点。后面可以一起观察，是睡眠、学校消耗，还是学习压力在叠加。
```

## 6. 可写入 growth_records

```json
{
  "scene_type": "emotional",
  "signal_type": "情绪承接力变化",
  "content": "孩子近期被提醒后更容易烦，且恢复时间变长",
  "importance": "high",
  "direction": "warning"
}
```

# 十一、沟通互动信号

## 1. 定义

孩子在和家长沟通时的反应方式发生变化。

## 2. 常见表现

正向：

- 从沉默变成能说一句；
- 从顶嘴变成说原因；
- 从“随便”变成表达具体不愿意；
- 冲突后愿意回来说；
- 能接受家长换一种问法；
- 能对安排提出条件。

中性：

- 从沉默变成敷衍；
- 从顶嘴变成关门；
- 从回避变成说无所谓。

预警：

- 以前能说，现在持续沉默；
- 一提某话题就关闭；
- 表面答应越来越快但执行更弱；
- 家长越问，孩子越退。

## 3. 判断重点

沟通信号往往和家庭互动循环相关。

需要判断：

```text
这次变化是孩子更打开了，还是换了一种关闭方式？
```

## 4. 前台表达

```text
这次他愿意多说一句，其实值得记一下。对这个孩子来说，变化不一定是马上讲很多，而是从完全关掉到愿意露出一点真实想法。
```

## 5. 可写入 growth_records

```json
{
  "scene_type": "communication",
  "signal_type": "沟通开放度变化",
  "content": "孩子在被问作业时没有直接沉默，而是说出一点具体原因",
  "importance": "high"
}
```

---

# 十二、手机与休息边界信号

## 1. 定义

孩子使用手机、争取休息、恢复方式、休息边界相关行为发生变化。

## 2. 常见正向信号

- 能说出“我想休息十分钟”；
- 完成一段后拿手机，但能按时停；
- 愿意讨论手机规则；
- 能接受先做一件再休息；
- 找到手机之外的恢复方式；
- 休息后能回来继续。

## 3. 常见中性信号

- 手机从学习前变成完成后出现；
- 原来偷偷玩，现在明说想玩一会儿；
- 原来一拿停不下，现在能停但还要提醒。

## 4. 常见预警信号

- 无任务时也停不下来；
- 睡前手机明显影响睡眠；
- 手机从恢复变成逃避所有任务；
- 一说手机就爆；
- 除手机外几乎没有恢复方式；
- 偷偷玩频率增加。

## 5. 判断重点

手机信号一定要看时间点：

```text
学习前 / 学习中 / 完成后 / 无任务 / 睡前
```

## 6. 前台表达

```text
这个变化挺关键。如果他是在完成一段任务后拿手机，而且能停下来，那它不一定只是逃避，也可能是在找一段明确的恢复时间。
```

## 7. 可写入 growth_records

```json
{
  "scene_type": "phone_rest",
  "signal_type": "休息边界变化",
  "content": "孩子完成一段任务后提出休息十分钟，并能按约定回来",
  "importance": "high",
  "direction": "positive"
}
```

---

# 十三、自我管理与责任感信号

## 1. 定义

孩子在安排任务、承担责任、做选择、兑现承诺方面出现变化。

## 2. 常见正向信号

- 主动说先做什么；
- 自己提出一个可执行安排；
- 承认某件事没做到；
- 主动补一个小任务；
- 能对规则提出条件；
- 能记得之前说过的安排；
- 对自己的时间有一点规划。

## 3. 常见中性信号

- 口头答应，但计划模糊；
- 愿意讨论安排，但执行弱；
- 能开始，但需要外部提醒；
- 对规则有意见，但能说出来。

## 4. 常见预警信号

- 承诺越来越快，但执行越来越弱；
- 对任何安排都说随便；
- 家长不催完全不动；
- 对自己任务没有边界感；
- 一遇到压力就完全退回被动。

## 5. 判断重点

责任感不能用单次事件下结论。

不要写：

```text
孩子没有责任感。
```

应写：

```text
孩子在某场景下尚未形成稳定自我安排，需要继续观察其是否能承担小范围任务。
```

## 6. 前台表达

```text
这件事可以放进您之前提到的“责任感”里一起观察。现在不急着看他能不能完全自觉，更重要的是：他能不能先承担一个很小、边界清楚的安排。
```

## 7. 可写入 long_term_goal 关联记录

```json
{
  "scene_type": "self_management",
  "signal_type": "责任感观察",
  "content": "孩子能对一个小任务提出自己的安排，但执行稳定性仍需观察",
  "related_goal": "责任感与自我管理",
  "importance": "medium"
}
```

---

# 十四、兴趣与能量来源信号

## 1. 定义

孩子在兴趣、放松、能量恢复、自主活动方面出现变化。

## 2. 常见正向信号

- 主动提起喜欢的事；
- 恢复以前的兴趣；
- 找到手机之外的放松方式；
- 愿意运动、画画、听音乐、和朋友聊天；
- 对某个非学习领域出现主动性；
- 分享自己最近关注的东西。

## 3. 常见预警信号

- 以前喜欢的事都不做了；
- 只剩手机；
- 什么都说没意思；
- 兴趣下降伴随睡眠或情绪变化；
- 不再和朋友交流；
- 原本有热情的事也变成应付。

## 4. 判断重点

兴趣变化是理解孩子状态的重要窗口。

如果兴趣下降，不要只解释为懒或沉迷。

可能关联：

- 精力透支；
- 情绪低落；
- 学校压力；
- 同伴变化；
- 被评价为“不务正业”后收回兴趣；
- 时间被学习挤压。

## 5. 前台表达

```text
如果连原来真正喜欢的事也不太碰了，这就不只是学习态度问题，更要看他最近整体精力是不是被消耗得比较厉害。
```

## 6. 可写入 growth_records

```json
{
  "scene_type": "interest",
  "signal_type": "兴趣变化",
  "content": "孩子近期不再主动参与原本喜欢的活动",
  "importance": "high",
  "direction": "warning"
}
```

---

# 十五、学校同伴与归属感信号

## 1. 定义

孩子在学校、老师、同伴、班级归属感方面出现变化。

## 2. 常见正向信号

- 主动聊同学；
- 提到学校中的具体事件；
- 愿意说老师或班级情况；
- 主动参加活动；
- 和朋友有稳定联系；
- 对学校生活有具体反馈。

## 3. 常见预警信号

- 突然不愿聊学校；
- 回家话变少；
- 以前提朋友，现在不提；
- 对某个老师或同学明显回避；
- 说不想上学；
- 周末提到学校就烦；
- 成绩没大变但状态变低。

## 4. 判断重点

学校同伴信号经常被家长误认为学习态度问题。

需要区分：

```text
学习压力
同伴关系
老师关系
班级归属
分班换座
考试后位置变化
```

## 5. 前台表达

```text
孩子不聊学校，不一定是没事，也不一定是故意瞒着。有时候是他还没想好怎么说，或者一说就担心后面被追问很多。
```

## 6. 可写入 pending_observation

```json
{
  "content": "继续确认孩子不愿聊学校，是学习压力、同伴关系，还是不想被追问",
  "related_scene": "school_social",
  "priority": "high"
}
```

---

# 十六、家庭互动有效经验信号

## 1. 定义

某一次家长换了一种方式后，孩子反应变好，这属于高价值成长信号。

它不只记录孩子，也记录家庭互动中的“有效经验”。

## 2. 常见表现

- 家长少追问后，孩子反而多说了一句；
- 家长先确认边界后，孩子抵触降低；
- 家长不马上讲道理，孩子愿意留下来；
- 家长把任务拆小后，孩子能开始；
- 家长没有临时加任务，孩子完成后更平稳；
- 家长承认之前判断不准，孩子没继续对抗。

## 3. 判断重点

这类信号非常重要，因为它能形成后续沟通策略的依据。

## 4. 前台表达

```text
这个经验值得存一下：这次您没有继续追问原因，而是先问他卡在哪一步，孩子反而愿意多说一点。后面类似作业场景，可以先把“为什么”换成“卡在哪一步”。
```

## 5. 可写入 family_interaction_patterns

```json
{
  "pattern_name": "低追问下表达增加",
  "content": "当家长减少连续追问、改问具体卡点时，孩子更愿意表达一点真实困难",
  "confidence": 0.72,
  "status": "candidate"
}
```

## 6. 可写入 growth_records

```json
{
  "scene_type": "family_interaction",
  "signal_type": "有效互动经验",
  "content": "家长减少追问后，孩子愿意说出具体卡点",
  "importance": "high",
  "direction": "positive"
}
```

# 十七、成长信号强度分级

## 1. 低强度信号

特点：

- 单次出现；
- 变化不明显；
- 与旧画像关系弱；
- 未来复用价值有限。

处理：

```text
可以轻回应，不一定写入。
```

## 2. 中强度信号

特点：

- 有具体事实；
- 和旧画像有一定差异；
- 可能对后续判断有帮助；
- 但还需要观察。

处理：

```text
写 growth_records 或 pending_observations。
```

## 3. 高强度信号

特点：

- 明显改变旧理解；
- 能解释多个行为；
- 和长期目标相关；
- 家长确认有代表性；
- 孩子问卷支持；
- 对后续沟通策略有直接价值。

处理：

```text
写 growth_records + profile_update_candidates / family_interaction_candidates。
```

---

# 十八、成长信号方向标记

建议每条 growth_record 加 `direction` 字段：

```text
positive
neutral
warning
```

## 1. positive

孩子状态或互动出现正向变化。

示例：

```text
孩子愿意说出具体不会的地方。
```

## 2. neutral

变化本身尚不明确。

示例：

```text
孩子从学习前拿手机变成完成一段后拿手机。
```

## 3. warning

孩子状态可能下降或压力加重。

示例：

```text
孩子近期连原本喜欢的兴趣也不碰了。
```

推荐结构：

```json

  "direction": "positive",
```

# 二十二、和其他记忆字段的关系

## 1. growth_records 与 profile_entries

`growth_records` 记录单次或近期变化。

`profile_entries` 记录相对稳定的孩子特点。

例子：

```text
growth_record：
孩子今天说出“不知道从哪开始”。

profile_entry：
孩子在低压力场景下更容易暴露具体学习困难。
```

只有多次 growth_records 指向同一方向，才适合增强为 profile_entry。

---

## 2. growth_records 与 pending_observations

如果变化有意义但方向不明确，写：

```text
growth_records + pending_observations
```

例子：

```text
孩子从学习前拿手机变成完成一段后拿手机。
```

growth_record：

```text
手机出现时间发生变化。
```

pending_observation：

```text
继续确认孩子拿手机更偏恢复需求，还是仍然存在即时反馈依赖。
```

---

## 3. growth_records 与 long_term_goals

如果变化关联家长长期目标，要写关联字段。

例子：

```text
家长长期关注：责任感。
孩子主动提出先写数学再休息。
```

growth_record：

```text
孩子开始对任务顺序提出自己的安排。
```

关联：

```text
责任感与自我管理
```

---

## 4. growth_records 与 correction_candidates

如果成长信号明显改变旧判断，应同时生成纠偏候选。

例子：

旧判断：

```text
孩子拿手机主要是逃避学习。
```

新信号：

```text
连续三次都是完成一段任务后拿手机，并能按时回来。
```

应生成：

```text
correction_candidate：旧判断缩小适用范围，新增完成任务后的恢复需求。
```

---

# 二十三、前台表达规则

## 1. 成长信号前台不必总是卡片

可以有三种表达：

### A. 普通气泡 + 小字

适合轻变化。

```text
这个变化挺值得记一下。以前一说作业他更容易沉默，这次能说出“不知道从哪开始”，说明他至少把困难露出了一点点。
```

小字：

```text
已记录一个近期变化
```

### B. 成长信号卡

适合中高价值变化。

结构可包含：

```text
这次记录到的变化
可能说明什么
后面可以关注
```

### C. 周期小观察

适合多条成长信号汇总。

```text
这周有一个小变化：孩子不是完全不表达，而是在任务边界清楚时更容易说出一点真实困难。
```

---

## 2. 推荐句式

```text
这个变化挺值得记一下。
这和孩子之前的状态有一点不同。
它不一定是大变化，但对理解孩子挺有价值。
后面可以关注一下……
这次至少说明……
如果后面还能出现几次，就可以把它更新进孩子小档案。
```

---

## 3. 避免句式

```text
孩子已经明显进步了。
这说明孩子开始改变了。
系统检测到成长信号。
根据成长模型判断……
这代表孩子心理状态好转。
这是非常重要的转折点。
```

除非证据很强，不要夸大变化。

---

# 二十四、成长信号卡格式

成长信号卡不是每轮都用。

适合：

- 信号中高价值；
- 和旧画像明显不同；
- 家长需要看见变化；
- 后续值得持续观察。

推荐格式：

```text
这次记录到的变化：
孩子这次没有直接沉默，而是说出“不知道从哪开始”。

可能说明：
他并不是完全不想做，至少这次困难更像是任务启动和拆解问题。

后面可以关注：
如果下次把任务拆成很小一步，他是不是更容易开始。
```

底部按钮：

```text
有点像｜不太像｜补充一点｜存到小档案
```

---

# 二十五、不要记录的内容

以下内容不应直接作为成长信号写入。

## 1. 只有情绪，没有事实

```text
我今天真的很烦他。
```

处理：

```text
回应家长情绪，不写 growth_record。
```

## 2. 只有评价，没有行为

```text
他越来越懒了。
```

处理：

```text
拆事实，必要时追问。
```

## 3. 单次强烈判断

```text
他以后肯定完了。
```

处理：

```text
承接焦虑，回到当前事实。
```

## 4. 与孩子无关的家长单独情绪

```text
我今天工作也很累。
```

处理：

```text
可回应家长状态，不写孩子成长信号。
```

## 5. 无法定位场景的笼统描述

```text
他最近不太对。
```

处理：

```text
问一个关键细节。
```

# 二十六、成长信号抽取示例

## 示例 1：主动聊学校

家长输入：

```text
今天他居然主动跟我说学校里的事了。
```

旧画像：

```text
孩子平时不太愿意聊学校。
```

判断：

```text
表达开放信号，正向，中高价值。
```

回复：

```text
这个变化挺值得记一下。您之前提到过，孩子平时不是特别愿意主动聊学校，所以这次愿意说，至少说明当时他对您是有一点打开的。

后面可以关注一下，他是愿意继续说具体事，还是只浅浅提一句。
```

写入：

```json
{
  "scene_type": "school_social",
  "signal_type": "表达开放",
  "content": "孩子主动提到学校里的事",
  "direction": "positive",
  "importance": "medium",
  "difference_from_previous_profile": "此前孩子较少主动聊学校"
}
```

```text
孩子经常说都懂，但实际会错。
```

判断：

```text
学习卡点暴露信号，正向，高价值。
```

```json
  "direction": "positive",
  "importance": "high",
  "difference_from_previous_profile": "此前孩子更倾向于说都懂"
}
```

## 示例 3：手机出现时间变化

家长输入：

```text
他这两天倒不是一开始就玩手机了，是写完一段才拿。
```

```text
孩子过去常在学习开始前拿手机。
```

判断：

```text
手机使用变化，中性偏正向，需观察。
```


写入：

```json
{
  "scene_type": "phone_rest",
  "signal_type": "手机使用变化",
  "content": "孩子近期更多在完成一段任务后拿手机，而不是学习开始前",
  "direction": "neutral",
  "importance": "high",
  "difference_from_previous_profile": "此前手机更多出现在学习开始前"
}
```

待观察：

```json
{
  "content": "继续确认孩子完成一段后拿手机，是恢复需求还是仍存在停不下来的即时反馈依赖",

}
```

# 二十七、与阶段复盘的关系

成长信号积累到一定数量后，可以触发阶段复盘建议。

触发条件：

- 7 天内出现 3 条以上同类成长信号；
- 某个旧判断被多次新信号挑战；
- 家长长期目标相关信号反复出现；
- 孩子状态出现连续预警；
- 家庭互动有效经验出现 2 次以上；
- 家长主动问“整体怎么看”。

输出：

```json
{
  "should_trigger_review": true,
  "review_reason": "近期多条记录显示孩子在作业场景中从沉默转向表达具体卡点，可进行阶段小观察"
}
```

前台可说：

```text
这几次信息放在一起，已经能看到一个小变化了。后面可以帮您整理一次最近阶段的小观察，把孩子这段时间的变化单独拎出来。
```

---

# 二十八、最低执行标准

日常 Agent 每轮判断成长信号时，至少要问自己：

```text
1. 家长说的是具体事实，还是评价？
2. 这个事实和孩子旧画像有什么关系？
3. 它是普通事件，还是相对旧状态有变化？
4. 这个变化是正向、中性，还是预警？
5. 它对未来理解孩子有没有复用价值？
6. 应该写 growth_record，还是 pending_observation？
7. 是否需要同步更新 profile_entry、long_term_goal、family_interaction 或 correction？
8. 前台是否需要提示“已记录一个近期变化”？
```

---

## 二十九、最终一句话

成长信号不是为了把每件小事都存起来，而是为了让系统慢慢看见：

```text
孩子正在变什么；
家长和孩子的互动正在变什么；
哪些旧判断需要被验证、增强或修正；
哪些小变化值得被家长看见。
```

> 日常 Agent 的长期价值，就体现在这些小信号被持续记录、对照和更新里。
