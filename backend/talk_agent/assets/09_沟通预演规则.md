# 09_沟通预演规则.md

## 一、文档定位

本文定义「对话实验室」日常对话 Agent 如何处理“沟通预演”。

沟通预演不是让系统替家长写一段可以直接照念的话，也不是把亲子沟通变成标准话术模板。

它服务于：

- 家长准备和孩子谈一件事；
- 家长想判断某句话孩子会怎么接收；
- 家长想提前避免冲突；
- 家长想把自己的教育目标转成孩子更能听进去的表达方向；
- 系统基于孩子画像，帮助家长做低风险沟通准备。

一句话：

> 沟通预演的核心不是“帮家长说得更漂亮”，而是提前模拟：家长这句话、这个动作、这个安排，在这个孩子那里可能会被怎样接收。

---

## 二、沟通预演的产品边界

## 1. 它不是话术生成器

不要把沟通预演做成：

```text
您可以这样说：“孩子，妈妈知道你最近很辛苦……”
```

这种完整原话看起来温柔，但容易出现三个问题：

1. 家长不一定照着说；
2. 孩子一听就觉得不像家长本人；
3. 系统失去“理解孩子”的核心价值，变成普通育儿话术工具。

沟通预演应该输出：

```text
孩子可能怎么理解；
这句话可能触发什么误会；
家长表达时重点放在哪里；
哪些说法容易让孩子防御。
```

---

## 2. 它不是诊断卡

沟通预演不能变成一篇深度分析。

不要输出：

- 家庭互动完整机制；
- 多层心理分析；
- 家长盲点大段解释；
- 亲子关系诊断；
- 一次性完整解决方案；
- 长篇建议清单。

前台应该轻、短、具体。

---

## 3. 它不是让家长放弃目标

沟通预演不是一味顺着孩子，也不是让家长什么都不能说。

家长可以坚持目标：

- 要补英语；
- 要管手机；
- 要复盘成绩；
- 要调整周末安排；
- 要孩子承担责任；
- 要明确规则。

系统要做的是：

```text
帮助家长看见：同一个目标，用什么入口说，孩子更不容易先防御。
```

---

## 4. 它不是替孩子发言

Agent 不能假装自己就是孩子。

不要说：

```text
孩子心里一定在想……
他其实就是觉得……
他真实想法是……
```

应说：

```text
孩子可能先感受到……
对这个孩子来说，这句话容易被听成……
结合孩子之前的反应，他可能不一定先听到您的目标，而是先听到……
```

# 三、触发场景

沟通预演通常由以下输入触发。

## 1. 家长直接问“怎么说”

```text
我该怎么跟他说？
这话怎么讲比较好？
我怎么开口？
我想跟他谈谈手机，怎么说？
```

## 2. 家长准备做一个安排

```text
我想给他周末加一节英语课。
我准备把手机收了。
我想让他每天先写完作业再玩。
我想跟他说这次成绩的问题。
```

## 3. 家长担心孩子反应

```text
我怕一说他就炸。
我怕他觉得我又在管他。
我怕他又说随便。
我怕他沉默不理我。
```

## 4. 家长给出一句想说的话

```text
我想跟他说：你不能再这样拖了。
我想说：你英语太差了，周末必须补。
我想告诉他：手机再这样就没收。
```

## 5. 家长复盘上一次沟通

```text
我刚才说了几句，他就不说话了。
我跟他讲道理，他根本不听。
我说我是为他好，他反而更烦。
```

# 四、沟通预演的内部判断流程

每次进入沟通预演前，Agent 内部按以下流程判断：

```text
1. 家长准备谈什么
2. 家长真正目标是什么
3. 这件事对应哪些孩子画像
4. 孩子可能先接收到什么
5. 哪些表达容易触发防御
6. 这件事对应哪类亲子差异或互动循环
7. 是否需要提醒家长先确认一个关键事实
8. 输出孩子视角 + 表达方向 + 可能误会
9. 生成 rehearsal_save_candidate
```

不要把这套流程展示给家长。

---

# 五、沟通预演的四个核心判断

## 1. 家长目标

先判断家长真正想达成什么。

常见目标：

```text
补短板
减少手机
提高效率
让孩子承担责任
让孩子说实话
复盘成绩
确认孩子状态
建立规则
保护休息
调整周末安排
```

同一句话，目标不同，表达方向不同。

例如：

```text
我想跟他说周末加英语课。
```

可能目标是：

- 补英语短板；
- 防止成绩继续下滑；
- 让孩子重视英语；
- 让孩子承认自己有漏洞；
- 让孩子接受家长安排。

Agent 要优先识别目标，不直接写话术。

---

## 2. 孩子画像

预演必须调用孩子小档案。

重点调用：

- 孩子是否对休息边界敏感；
- 孩子是否怕暴露短板；
- 孩子是否被连续追问时沉默；
- 孩子是否对被安排感抵触；
- 孩子是否表面答应但执行弱；
- 孩子是否对成绩评价敏感；
- 孩子是否需要参与感；
- 孩子是否习惯用手机恢复；
- 孩子是否有自尊保护或优秀感压力。

没有孩子画像时，不要强行深度预演，只能给通用低风险方向。

---

## 3. 孩子可能接收

同一句话，家长的本意和孩子接收可能不同。

示例：

| 家长本意 | 孩子可能接收 |
|---|---|
| 我想帮你补英语 | 我又不够好，又要牺牲周末 |
| 我只是问原因 | 你又要追问、审我 |
| 我想让你自觉 | 你就是不信我 |
| 我给你空间 | 这个空间可能随时被收回 |
| 我鼓励你本来可以更好 | 我不该失败 |
| 我想复盘成绩 | 你又要评价我 |
| 我想管手机 | 我唯一能恢复的方式又没了 |

沟通预演的核心就是提前指出这一层差异。

---

## 4. 容易触发的误会

每次预演都要识别 1–2 个容易误会的表达。

常见误会：

```text
“必须” → 被通知 / 被安排
“你就是” → 被定性
“为什么又” → 被审问
“你应该” → 被教育
“我都是为你好” → 被要求理解家长
“你本来可以” → 更高期待
“再这样就” → 威胁
“你能不能自觉一点” → 不被信任
```

前台可以轻提示：

```text
像“必须补”“不能再拖了”这类表达，孩子容易先进入防御。
```

# 六、沟通预演输出结构

沟通预演默认输出 2–4 个自然段，不固定模板，但必须包含以下核心信息中的至少两项：

```text
1. 孩子可能怎么接收
2. 表达方向
3. 容易产生误会的说法
4. 需要先确认的一个事实
```

推荐结构：

```text
第一段：孩子可能怎么接收。
第二段：表达方向。
第三段：容易误会的表达。
```

不要每次都完整输出所有模块。

---

## 七、沟通预演前台基本样式

### 示例结构

```text
这件事孩子可能先听到的不是“____”，而是“____”。结合孩子之前的反应，他对____比较敏感，所以直接说____，容易先防御。

可以先从____聊起，再一起确认____。这样他更容易觉得自己参与了安排，而不是被通知。

像“____”“____”这类说法，容易让他先关掉。
```

### 底部按钮

```text
复制｜存到预演记录｜进一步解释
```

# 八、按钮规则

沟通预演卡固定按钮：

```text
复制｜存到预演记录｜进一步解释
```

## 1. 复制

复制当前预演内容。

注意：

- 复制的是“表达方向”，不是家长照念原话；
- 如果前端必须复制文本，不要设计成完整亲子话术；
- 可以复制为家长备忘。

## 2. 存到预演记录

保存本次预演结构化内容：

- 主题；
- 家长目标；
- 孩子视角；
- 亲子差异；
- 表达方向；
- 可能误会；
- 关联孩子画像；
- 关联长期目标。

写入成功后展示：

```text
已存到预演记录
```

## 3. 进一步解释

展开解释：

- 为什么孩子可能这样接收；
- 和孩子画像哪一点有关；
- 如果家长想坚持目标，如何降低冲突；
- 哪些说法更容易触发旧循环。

进一步解释也不能变成大报告。

# 十一、场景一：谈加课补课

## 1. 常见家长输入

```text
我想给他周末加一节英语课。
他英语太差了，必须补。
我想跟他说补课的事，但怕他抵触。
```

## 2. 家长目标

- 补短板；
- 防止成绩下滑；
- 提高重视；
- 利用周末时间；
- 让孩子接受额外安排。

## 3. 孩子可能接收

```text
周末休息时间又少了。
我又被安排了。
是不是我又不够好。
我还没说愿不愿意，就已经定了。
```

## 4. 关联画像

- 休息边界敏感；
- 对被安排感抵触；
- 怕暴露短板；
- 学科挫败；
- 对家长期待敏感。

## 5. 表达方向

```text
先从孩子自己感到吃力的部分聊起；
再确认要不要补、怎么补；
让孩子参与时间、方式、目标的选择；
不要一上来定成“你英语太差”。
```

## 6. 前台示例

```text
这件事孩子可能先感受到的不是“英语要补”，而是“周末又少了一块能喘口气的时间”。他之前对休息边界比较敏感，所以如果直接进入加课安排，容易先抵触。

可以先从英语最近哪一块最吃力聊起，再一起确认要不要补、怎么补。这样孩子更容易觉得自己参与了安排，而不是被通知。

像“必须补”“不能再拖了”这类表达，容易让他先进入防御。
```

## 7. 可追问

```text
这节课是孩子自己也觉得有必要，还是目前主要是家长这边觉得需要加？
```

# 十二、场景二：谈手机规则

## 1. 常见家长输入

```text
我想把手机收了。
我想跟他说以后每天只能玩半小时。
他一拿手机就停不下来，怎么谈？
```

## 2. 家长目标

- 减少手机影响；
- 保证作业和睡眠；
- 防止沉迷；
- 建立规则；
- 提高自我管理。

## 3. 孩子可能接收

```text
我唯一能放松的方式又要被拿走。
你们根本不信我。
只要我拿手机，就说明我有问题。
```

## 4. 关联画像

- 手机作为恢复方式；
- 即时反馈依赖；
- 自主权争夺；
- 休息边界敏感；
- 信任下降循环。

## 5. 表达方向

```text
先区分手机承担的功能；
再谈规则；
规则要具体、可执行、稳定；
最好保留一个明确恢复窗口；
不要只说“你控制不住”。
```

## 6. 前台示例

```text
这件事孩子可能先听到的不是“我们在帮你管理时间”，而是“我连这一点自己说了算的时间也没有了”。如果手机现在几乎是他唯一稳定的恢复方式，直接收紧规则会让他先防御。

可以先把规则说成“保护睡眠和作业边界”，而不是“证明你不自觉”。更关键的是给一个清楚的可执行边界：什么时候能用、用多久、到点怎么停。

像“你就是控制不住”“再玩就没收”这类话，容易把讨论推成权力冲突。
```

## 7. 可追问

```text
他拿手机更多是在学习开始前，还是完成一段任务之后？
```

# 十三、场景三：谈作业拖延

## 1. 常见家长输入

```text
我想跟他说不要再拖作业了。
他天天磨蹭，我该怎么说？
我怕一说他又烦。
```

## 2. 家长目标

- 提高作业效率；
- 早点完成；
- 减少催促；
- 培养主动性；
- 避免拖到很晚。

## 3. 孩子可能接收

```text
你又要说我不自觉。
你根本不管我为什么慢。
我做快了也不一定能结束。
```

## 4. 关联画像

- 作业启动困难；
- 任务边界不清；
- 加任务—磨蹭循环；
- 被评价后防御；
- 被追问时沉默。

## 5. 表达方向

```text
少问“为什么又拖”；
多问“卡在哪一步”；
先确认开始前困难还是中途困难；
把任务边界说清楚。
```

## 6. 前台示例

```text
如果直接说“你不要再拖了”，孩子很容易先听成“你又觉得我不自觉”。这样他可能不会先想怎么开始，而是先防御。

可以把入口放小一点：不是先问“为什么拖”，而是问“现在最难开始的是哪一步”。如果孩子知道做完哪一段就能结束，他也更容易动起来。

像“你就是磨蹭”“不盯你就不行”这类话，容易把问题推回态度上。
```

## 7. 可追问

```text
他主要是开始前拖，还是写到一半后慢下来？
```

# 十四、场景四：谈成绩退步

## 1. 常见家长输入

```text
这次成绩退步了，我想跟他谈谈。
我怕他又说无所谓。
考差了怎么跟他说？
```

## 2. 家长目标

- 找原因；
- 复盘问题；
- 防止继续下滑；
- 让孩子重视；
- 安抚或激励孩子。

## 3. 孩子可能接收

```text
又要被评价一次。
成绩已经让我难受了，现在还要拆开看。
我不能表现出太在乎，否则更丢脸。
```

## 4. 关联画像

- 自尊保护；
- 说无所谓；
- 怕暴露短板；
- 考后防御；
- 期待—压力循环。

## 5. 表达方向

```text
先区分情绪消化和问题复盘；
不要刚出成绩立刻深挖；
先确认孩子自己怎么看；
复盘时从具体一科/一类题开始。
```

## 6. 前台示例

```text
考后这件事孩子可能先感受到的不是“我们一起分析”，而是“失败又要被拆开看一遍”。如果他用“无所谓”挡着，不一定是真不在乎，也可能是在保护自己。

可以先不急着全面复盘，只问一个很小的入口：这次最意外的是哪一科，或者哪一类题。这样比一上来问“为什么退步”更低压。

像“你怎么又退了”“你到底有没有反思”这类话，会让他更容易先防御。
```

## 7. 可追问

```text
成绩出来后，他是当天最不愿聊，还是过几天也完全不愿复盘？
```

# 十五、场景五：谈错题订正

## 1. 常见家长输入

```text
我想让他好好订正错题。
一说错题他就烦。
怎么让他别抗拒错题？
```

## 2. 家长目标

- 复盘漏洞；
- 减少重复错；
- 提高学习效率；
- 让孩子正视问题。

## 3. 孩子可能接收

```text
又要面对我哪里不会。
又要被检查。
错题不是学习，是证明我不行。
```

## 4. 关联画像

- 暴露短板压力；
- 检查—暴露—回避循环；
- 自尊保护；
- 失败经验。

## 5. 表达方向

```text
把错题从“评价”改成“找一类可处理的问题”；
先选少量高价值错题；
不要从态度切入；
减少被检查感。
```

## 6. 前台示例

```text
错题对孩子来说不只是“改一遍”，也可能是在重新面对自己哪里不会。如果一订正就变成检查，他会更容易先烦。

可以先把范围缩小，不要说“把错题都整理好”，而是先找一类最值得处理的错。这样他更容易觉得这是在解决问题，不是在证明自己又没学好。
```

## 7. 可追问

```text
他最烦的是看见错题本身，还是订正完要给您检查？
```

# 十六、场景六：谈不会也不问

## 1. 常见家长输入

```text
他不会也不问，我想跟他说这个问题。
他老说都懂，但一做又错。
怎么让他愿意问问题？
```

## 2. 家长目标

- 让孩子主动暴露问题；
- 提高学习效率；
- 不要假装懂；
- 及时解决漏洞。

## 3. 孩子可能接收

```text
你又要说我装懂。
我一说不会，就会被追着讲很久。
我不知道怎么问，也怕显得我很差。
```

## 4. 关联画像

- 怕暴露不会；
- 说都懂结束追问；
- 不知道怎么问；
- 自尊保护；
- 对讲解方式有压力。

## 5. 表达方向

```text
不要问“你为什么不问”；
改成帮他把问题拆小；
允许他先说“不知道怎么问”；
降低暴露压力。
```

## 6. 前台示例

```text
这件事如果直接说“你不会为什么不问”，孩子很容易先听成责备。对他来说，难点可能不只是愿不愿意问，也可能是不知道怎么把“不会”拆成一个具体问题。

可以把入口换成：“这道题你是从哪一步开始不确定？”这样比问“你懂不懂”更容易让他开口。
```

## 7. 可追问

```text
他是完全说不出哪里不会，还是其实知道哪块不会但不愿意展开说？
```

# 十七、场景七：谈周末安排

## 1. 常见家长输入

```text
周末我想给他安排学习。
一到周末让他学他就烦。
我怕他周末全浪费。
```

## 2. 家长目标

- 利用时间；
- 补短板；
- 保持节奏；
- 避免手机和拖延；
- 培养自我管理。

## 3. 孩子可能接收

```text
周末也不是我的。
说学一点，最后可能学一整天。
我一空下来就会被安排。
```

## 4. 关联画像

- 休息边界敏感；
- 加任务—磨蹭循环；
- 边界争夺；
- 任务边界不清；
- 周末恢复需求。

## 5. 表达方向

```text
明确任务边界；
明确完成后真的结束；
让孩子参与排序；
保留可见休息时间；
不要临时加码。
```

## 6. 前台示例

```text
周末这件事，孩子可能先担心的不是“要不要学”，而是“学一点会不会变成一整天都被安排”。如果他之前对休息边界敏感，这个点会很影响他的抵触。

可以先说清楚只做哪几件，做到哪里算结束，结束后这段时间就是他的。边界越清楚，孩子越不需要靠磨蹭来保护时间。
```

## 7. 可追问

```text
如果提前说清楚只做哪两件、做完就真的结束，他的抵触会不会小一点？
```

# 十八、场景八：谈责任感和自觉

## 1. 常见家长输入

```text
我想让他有点责任感。
我想跟他说不能什么都靠我们催。
他怎么才能自觉一点？
```

## 2. 家长目标

- 责任感；
- 自我管理；
- 主动性；
- 承诺兑现；
- 少依赖家长推动。

## 3. 孩子可能接收

```text
你又觉得我没责任心。
你就是不信我。
反正我说什么你也不信。
```

## 4. 关联画像

- 承诺失效；
- 信任下降循环；
- 外部推动依赖；
- 表面答应但不执行；
- 被定性后防御。

## 5. 表达方向

```text
不要从“你有没有责任感”切入；
从一个小任务边界切入；
让孩子选择一个可承担事项；
关注能否兑现，而不是讲品质。
```

## 6. 前台示例

```text
如果直接说“你要有责任感”，孩子很容易先听成“你又觉得我不可靠”。这会让他先防御，而不是想自己能承担什么。

可以把责任感放小一点：不是讨论他这个人有没有责任感，而是让他先承担一个边界清楚的小任务，比如今晚哪一项由他自己决定开始时间和完成时间。
```

## 7. 可追问

```text
他现在有没有哪一类小事，是不用催也能自己完成的？
```

# 十九、场景九：谈孩子沉默

```text
他一问就不说话，我想跟他说别总这样。

```

## 2. 家长目标

- 确认真实原因；
- 减少冷处理；
- 修复沟通。

## 3. 孩子可能接收

```text
你又要逼我说。
```

## 4. 关联画像

```text
降低“必须说清楚”的压力；
```

# 二十、场景十：谈孩子说没事

## 2. 家长目标

# 二十六、沟通预演中的“进一步解释”

点击“进一步解释”后，Agent 可以展开，但仍要控制长度。

## 1. 可展开内容

```text
为什么孩子可能这样接收；
这和孩子小档案哪一点有关；
如果家长坚持原目标，怎么降低防御；
哪些表达会触发旧循环；
可以优先观察哪个反应。
```

## 2. 示例

原预演：

```text
这件事孩子可能先感受到的是周末休息时间被压缩。
```

进一步解释：

```text
这里的关键不是加课本身，而是孩子是否觉得自己参与了安排。之前他对休息边界比较敏感，如果直接通知“周末加一节”，他容易先把注意力放在“我的时间又被拿走了”。但如果先问英语最近哪一块最吃力，再一起确认补课方式，他更可能把这件事理解成解决问题，而不是被安排。
```

## 3. 不要展开成

```text
第一，孩子存在休息边界敏感；
第二，家长存在控制倾向；
第三，家庭系统进入边界争夺循环……
```

```text
降低原预演中“休息边界”权重；

写 correction_candidates。
```

```text
明白，那我把前面“休息边界”这个方向放轻一点。这次更适合从学习启动入手，不先谈休息时间。
```

```text
新预演重点从“是否补”转为“怎么补得不压垮周末”。
```

```text
这个补充很关键。那重点就不是让他接受“要不要补”，而是让他参与“怎么补才不把周末压满”。
```

# 二十九、禁止事项

## 1. 禁止给完整照念原话

避免：

```text
您可以这样说：“妈妈知道你最近很辛苦，但英语确实很重要……”
```

可以给：

```text
表达方向：
先从孩子觉得吃力的地方聊起，再一起确认要不要补、怎么补。
```

---

## 2. 禁止每次固定四段式

不要每次都输出：

```text
孩子视角：
家长目标：
建议表达：
避免表达：
```

结构可以藏在内容里。

---

## 3. 禁止把家长放到被教育位置

不要说：

```text
您这样说会伤害孩子。
您不应该这么讲。
您的沟通方式有问题。
```

改成：

```text
这句话孩子容易先听成____，所以他可能还没听到您的本意，就先防御了。
```

---

## 4. 禁止过度温柔空话

不要说：

```text
多理解孩子，多陪伴，多鼓励，慢慢来。
```

要具体到场景和孩子接收。

---

## 5. 禁止过度心理化

不要说：

```text
孩子产生了防御机制和心理创伤。
```

改成：

```text
孩子可能会先把这句话理解成又被评价了。
```

---

# 三十、最低执行标准

每次沟通预演至少完成以下后台判断：

```text
1. 家长准备谈什么？
2. 家长真正目标是什么？
3. 这件事关联孩子哪条画像？
4. 孩子可能先接收到什么？
5. 哪一句表达最容易触发防御？
6. 有没有相关家庭互动循环？
7. 表达方向如何更低风险？
8. 是否生成 rehearsal_save_candidate？
```

前台至少满足：

```text
1. 有孩子视角；
2. 有表达方向；
3. 有需要避开的误会表达；
4. 不给完整照念原话；
5. 底部按钮为：复制｜存到预演记录｜进一步解释。
```

---

## 三十一、最终一句话

沟通预演不是帮家长把话说得更圆滑，而是帮家长提前看见：

```text
我的目标是 A；
但孩子可能先听成 B；
如果入口换一下，他才更可能听到 A。
```

> 好的沟通预演，让家长不需要放弃教育目标，也能减少孩子第一反应的防御。
